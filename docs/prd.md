# 부여ON PRD
## 1. UX 목표 및 서비스 방향성
### 1.1 문제 정의 (Problem Statement)
- **단발성·파편화된 관광 경험**
	기존 지자체 관광 앱은 단순히 유적지 정보를 나열하는 책자형 서비스에 그쳐 유저의 자발적인 탐방 동기를 유발하지 못한다.
- **지역 상권과의 연계 부족**
	관광객의 방문이 실제 골목상권(식당·카페) 소비로 원활하게 연결되지 않는다.
- **낮은 리텐션(Retention)**
	여행이 끝남과 동시에 앱이 즉시 삭제되거나 잊힌다.
### 1.2 인사이트 (Insights)
- **게이미피케이션 탐방**
	유저는 단순 눈요기보다 퀴즈, 사진 인증 등 직접 미션을 수행하고 즉각적인 리워드를 얻을 때 탐방 몰입도가 급증한다.
- **군민증 기반의 통합 경험**
	복잡한 쿠폰 다운로드보다 `디지털 군민증 바코드` 하나로 보유 포인트를 확인하고 제시하는 경험이 사용자에게 직관적이다. MVP의 바코드는 시연용이며 실제 결제나 포인트 차감은 수행하지 않는다.
- **라스트 마일(Last-Mile) 감성 회고**
	여행이 끝나는 시점에 Spotify Wrapped나 iPhone 추억 비디오처럼 내 여정을 감성적으로 요약해 주면 깊은 여운과 함께 높은 앱 만족도 및 재방문 욕구를 형성한다.
### 1.3 Key Design Idea
> 디지털 시민이 되어 부여를 탐험하고, 포인트로 골목을 살리며, 추억을 안고 돌아가는 로컬 여행 플랫폼
### 1.4 구체적 UX 목표
1. **초기 몰입**
	단계별 인터랙티브 군민증 발급으로 소속감을 형성한다.
2. **현장 탐방**
	카카오맵 톤 지도 위에 `유적지`, `퀴즈`, `내 위치` 3종 마커를 제공해 직관적인 탐방을 유도한다.
3. **지역 상권 선순환 가능성 검증**
	미션 성공 리워드 포인트와 시연용 군민증 바코드로 향후 골목상권 연계 경험을 검증한다.
4. **감성적 마무리**
	Spotify Wrapped와 iPhone 추억 슬라이드 연출을 통해 차별화된 여정 종료 경험을 제공한다.
## 2. 주요 사용자 (User Persona & Context)
### 2.1 사용자 페르소나
| 페르소나 | 특성 | 니즈 |
| --- | --- | --- |
| MZ 세대 감성 로컬 탐방러 | 2030세대, 디지털 및 모바일 앱 숙련도가 높고 감성 스폿·인증샷 및 숏폼·스토리 형태의 콘텐츠를 선호 | 남들과 다른 특별한 지역 탐방, 소소한 재미가 있는 퀴즈·미션, 사진 기록 |
| 아이와 함께 여행하는 부모 | 3040세대, 캐시워크와 같이 포인트를 쌓는 서비스에 익숙 | 포인트를 이용한 로컬 맛집·상권 할인, 주변 맛집 추천 |
### 2.2 사용 맥락 (Context)
#### 여행 중 — 부여 현장
1. 지도를 보며 가볼 만한 유적지와 카페·식당을 카테고리별로 탐색하고 관심 장소를 저장(북마크)한다.
2. 지도를 보며 이동한다.
3. 퀴즈 마커를 발견한다.
4. OX·객관식·카메라 인증 챌린지를 수행한다.
5. 포인트를 획득한다.
6. 군민증 바코드와 보유 포인트를 확인하고 상권 연계 경험을 시연한다.
#### 여행 후 — 귀가 길 또는 IC 통과 시
- `부여 떠나기` 스토리를 실행한다.
- 오늘 하루 걸었던 동선과 사진을 감성적인 슬라이드쇼로 회고한다.
## 3. 구현할 MVP 및 핵심 기능
Figma PRD에 서술된 기능을 다음 5가지 MVP 기능으로 정리한다.
1. **인터랙티브 디지털 군민증 발급**
	- 이름, 프로필 캐릭터, 카드 테마 설정
	- 보유 포인트 확인과 시연을 위한 군민증 바코드 제공
2. **위치 기반 탐험 지도**
	- 유적지, OX·객관식·사진 인증 미션, 현재 위치 마커 제공
	- 관광지와 주변 골목상권 탐색 유도
3. **현장 미션**
	- OX·객관식 퀴즈
	- 카메라를 이용한 사진 인증 챌린지
4. **포인트 리워드 및 지역 상권 연계 시연**
	- 미션 성공 시 포인트 적립
	- 누적 적립 포인트를 기준으로 한 전체 회원 랭킹과 내 순위 조회
	- 군민증 바코드를 통한 지역화폐형 포인트 사용 경험 시연
5. **여정 회고 콘텐츠**
	- 미션 완료로 확정된 문화재 방문 기록, 탐방 시간, 획득 포인트, 촬영 사진 요약
	- Ken Burns 줌 효과가 적용된 감성 오토 슬라이드쇼
### 3.1 검증할 핵심 가설
#### 가설 1 — 게이미피케이션
지도의 퀴즈·사진 미션 마커가 유저의 유적지 방문 및 이동 거리를 증가시킬 것이다.
#### 가설 2 — 지자체 연동 리워드
군민증 바코드 기반 포인트 사용 경험이 유저의 로컬 골목상권 방문 의사를 높일 것이다.
#### 가설 3 — 라스트 마일 회고
스토리·추억 비디오 형태의 여정 요약이 여행 경험의 만족도를 높이고 재방문 의사를 끌어올릴 것이다.
## 4. 범위
### 4.1 포함 사항 (Included)
- 카카오 또는 Apple 소셜 인증
- `소셜 인증 → 회원 생성 → 필수 약관 동의 → 디지털 군민증 발급` 순서의 필수 온보딩. 부여 위치 확인은 퀴즈 여행 시작 시 수행한다.
- 디지털 군민증을 발급받은 회원만 시작할 수 있는 여행
- API와 서버 저장소 기반 회원·여행·포인트·저장 장소·군민증 데이터 유지
- 카메라 촬영 이미지의 서버 업로드
- 퀴즈와 사진 인증을 포함한 미션 완료 시 연결된 문화재의 방문 기록 생성
	- 같은 여행에서 같은 문화재의 미션을 여러 번 완료해도 방문 기록은 한 번만 생성한다.
- 여행 시작부터 종료 또는 현재 시각까지의 탐방 시간 제공
- 여행 종료 시 이번 여행에서 적립하고 아직 정산하지 않은 포인트만 남기거나 10×24시간 이월
	- 다른 여행에서 이월한 포인트는 이번 여행의 정산 대상에서 제외한다.
- 누적 적립 포인트를 기준으로 한 전체 회원 랭킹과 내 순위 조회
- Ken Burns 줌 효과가 적용된 감성 오토 슬라이드쇼
### 4.2 제외 사항 (Excluded)
- PG 결제, 지역화폐 연동, 실제 가맹점 포인트 차감
	- MVP의 군민증 바코드는 보유 포인트를 표시하는 시연 용도로만 사용한다.
- 이동 거리와 소모 칼로리 계산
	- MVP에서는 값을 계산하지 않고 조회 결과에 `null`을 제공한다.
- 복잡한 쿠폰 구매·교환권 커머스 모달
	- 사용자 경험 단순화를 위해 제외한다.
- 지도 위 복잡한 일반 상점 마커
	- 유적지와 퀴즈·사진 인증 미션 탐색에 집중한다.
