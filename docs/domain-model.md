# 도메인 모델과 규칙

## 모델링 기준

- 이 문서는 `관광데이터 유즈케이스`에 등장하는 사용자 목표와 규칙만 반영한다.
- 화면 이름이나 저장 방식이 아니라 서비스에서 의미가 있는 개념과 상태를 중심으로 정의한다.
- `배지`를 표준 용어로 사용하며, 화면의 `뱃지`와 같은 의미로 본다.

## 핵심 도메인 흐름

1. 사용자가 소셜 계정으로 가입하거나 로그인한다.
2. 신규 사용자가 필수 약관에 동의한다.
3. 필수 약관에 동의하고 부여에 도착한 사용자가 디지털 군민증을 만든다.
4. 디지털 군민증을 발급받은 사용자가 여행을 시작하고 장소와 미션을 탐색한다.
5. 사용자가 미션을 완료해 포인트와 배지를 획득한다.
6. 사용자가 여행을 끝내고 남은 포인트를 정산한다.
7. 사용자가 종료된 여행의 발자취를 조회한다.

## 도메인 관계 요약

| 도메인 | 핵심 모델 | 주요 관계 |
| --- | --- | --- |
| 회원·인증 | 회원, 소셜 계정, 인증 세션 | 회원은 소셜 계정으로 가입·로그인한다. |
| 약관 | 약관, 약관 동의 | 회원은 서비스 이용 전 필수 약관에 동의한다. |
| 군민증·프로필 | 디지털 군민증, 프로필, 캐릭터, 카드 테마, 바코드 | 회원은 하나의 활성 군민증과 프로필을 가진다. |
| 여행 | 여행 | 회원은 여행을 시작하고 종료한다. |
| 장소·저장 | 장소, 저장한 장소 | 회원과 장소는 저장 관계로 연결된다. |
| 미션 | 미션, 미션 참여 | 장소는 미션을 제공하고 회원은 여행 중 미션에 참여한다. |
| 포인트 | 포인트 잔액, 포인트 내역, 포인트 정산 | 미션 완료는 포인트 적립을 만들고 여행 종료 후 정산한다. |
| 배지 | 배지, 배지 조건, 획득 배지 | 회원 활동에서 메트릭 진행도를 계산하고 모든 조건 달성 시 배지를 지급한다. |
| 알림·설정 | 알림, 푸시 토큰, 알림 동의, 서비스 설정 | 회원 설정과 현재 인증 세션의 푸시 토큰에 따라 주변 퀴즈와 활동 알림을 제공한다. |
| 활동·발자취 | 방문 기록, 사진 기록, 여행 통계, 발자취 | 여행 중 활동을 모아 통계와 발자취를 구성한다. |

## 전역 필수 규칙

다음 규칙은 모든 도메인에 공통으로 적용하며, 도메인별 규칙과 충돌할 경우 이 규칙을 우선한다.

### 1. 중복 요청 처리

1. `Idempotency-Key`가 필요한 요청은 같은 회원이 같은 작업에 같은 키와 같은 요청 본문으로 다시 요청하면 최초 성공 응답을 반환한다.
2. 같은 키를 다른 요청 본문이나 작업에 재사용하면 `409 IDEMPOTENCY_KEY_REUSED`를 반환한다.
3. 이미 완료된 행동을 다른 키로 다시 요청해 허용되지 않은 상태 전이가 발생하면 상태별 오류 코드와 함께 `409`를 반환한다.
4. 다음 행동은 반드시 중복 결과 생성을 막는다.
	- 같은 소셜 계정의 회원 가입
	- 같은 장소 저장
	- 같은 미션 완료와 보상 지급
	- 같은 배지 획득
	- 같은 여행의 시작과 종료
	- 같은 여행의 포인트 정산
	- 같은 회원의 탈퇴 요청
5. 장소 저장처럼 HTTP 메서드 자체가 멱등인 작업은 이미 목표 상태이면 성공으로 처리한다.
6. 실패한 요청을 다른 키로 다시 시도한 경우 이전 요청이 실제로 반영됐는지 먼저 확인한 후 처리한다.

### 2. 포인트 정합성

1. 포인트 잔액이 변하면 반드시 같은 금액의 포인트 내역이 남아야 한다.
2. 포인트 잔액은 유효한 포인트 내역의 합계와 항상 일치해야 한다.
3. 포인트 잔액은 0보다 작아질 수 없다.
4. 하나의 미션 완료에는 포인트 보상을 한 번만 지급한다.
5. 미션 완료, 포인트 내역 생성, 포인트 잔액 변경은 하나의 처리 단위로 본다.
6. 여행 포인트 정산은 해당 여행에서 적립하고 아직 정산하지 않은 포인트만 대상으로 하며, `부여에 남기기`와 `다음에 이어서 쓰기` 중 하나로만 정산할 수 있다. 다른 여행에서 이월한 포인트는 영향을 받지 않는다.
7. 포인트 정산에 실패하면 잔액과 내역을 정산 전 상태로 유지한다.
8. MVP의 군민증 바코드 조회는 포인트 잔액을 차감하지 않는다.

### 3. 날짜와 시간대

1. 서비스의 날짜와 시간 판단 기준은 한국 표준시 `Asia/Seoul`이다.
2. `오늘`은 한국 표준시 00:00부터 다음 날 00:00 전까지다.
3. 여행 시작·종료, 방문, 미션 완료, 포인트 적립, 배지 획득, 알림 발생 시각은 해당 행동이 확정된 시각으로 기록한다.
4. 목록 정렬과 화면 표시는 한국 표준시 기준의 발생 시각을 사용한다.
5. `다음에 이어서 쓰기`를 선택한 포인트는 정산 완료 시각부터 `10×24시간` 동안 유효하다.
6. 유효기간의 종료 시각은 한국 표준시로 표시한다.

### 4. 삭제 정책

1. 로그아웃은 인증 세션만 종료하며 회원, 군민증, 포인트, 여행 기록을 삭제하지 않는다.
2. 저장한 장소 삭제는 회원과 장소의 저장 관계만 삭제하며 장소 정보와 방문 기록은 유지한다.
3. 회원 탈퇴가 확정되면 즉시 로그인을 차단한다.
4. 탈퇴 회원의 프로필, 군민증, 위치·여행·미션·사진·포인트·저장·배지·알림 설정·푸시 토큰 정보는 탈퇴 후 30일 이내에 파기한다.
5. 사진 인증 이미지는 서버에서 관리하며 해당 회원, 여행, 미션 기록과 연결한다.
6. 삭제 작업 일부가 실패해도 탈퇴 회원의 접근 권한을 복구하지 않고 삭제를 다시 시도한다.

### 5. 상태 전이

| 모델 | 허용 상태 전이 | 규칙 |
| --- | --- | --- |
| 회원 | 가입 전 → 활성 → 탈퇴 | 탈퇴한 회원은 활성 상태로 되돌리지 않는다. |
| 디지털 군민증 | 미발급 → 발급 | 프로필 수정은 발급 상태를 바꾸지 않는다. |
| 여행 | 시작 전 → 진행 중 → 종료 → 정산 완료 | 종료한 여행은 다시 진행 중으로 되돌리지 않으며 재방문 시 새 여행을 시작한다. |
| 미션 참여 | 잠김 ↔ 도전 가능 → 완료 | 위치에 따라 잠김과 도전 가능 상태가 바뀌며 완료 상태는 되돌리지 않는다. |
| 스페셜 퀴즈 | 도전 가능 → 기회 소진 또는 완료 | 기회가 소진되면 더 이상 도전할 수 없다. |
| 장소 저장 | 미저장 ↔ 저장 | 저장과 삭제로 두 상태 사이를 전환한다. |
| 포인트 정산 | 정산 대기 → 부여에 남김 또는 유지 | 한 번 확정한 정산 결과는 다른 결과로 다시 확정하지 않는다. |
| 배지 | 미획득 → 진행 중 → 획득 | 획득한 배지는 미획득 상태로 되돌리지 않는다. |
| 근처 퀴즈 알림 | 미동의 ↔ 동의 | 회원이 설정에서 변경할 수 있다. |
| 푸시 토큰 | 미등록 ↔ 등록 | 현재 인증 세션에서 등록·갱신·삭제할 수 있다. |

### 6. 위치 인증 기준

1. 군민증 생성과 여행 시작은 현재 위치가 부여 행정구역 안에 있을 때만 허용한다.
2. 미션 참여는 현재 GPS 위치와 미션 위치 사이의 직선거리가 100m 이내일 때만 허용한다.
3. 부여 행정구역 밖으로 이동한 사실만으로 여행을 즉시 종료하지 않고 회원의 종료 확인을 받는다.
4. 위치 권한이 없거나 현재 위치를 확인할 수 없으면 위치 인증이 필요한 행동을 허용하지 않는다.
5. 위치 재확인은 기존 위치가 아니라 새로 확인한 현재 위치를 기준으로 판단한다.
6. 저장 목록, 포인트 내역, 배지, 발자취 조회에는 위치 인증을 요구하지 않는다.
7. 부여 행정구역은 서버 애플리케이션에 포함된 버전 관리 대상 GeoJSON Polygon으로 고정한다.
8. 군민증 생성과 여행 시작 시 서버는 전달받은 위치가 이 Polygon 내부 또는 경계 위에 있는지 판정하며 외부 지오코딩 API에 의존하지 않는다.

### 7. 사용자 권한

1. 로그인하지 않은 사용자는 가입, 로그인, 약관 확인 외의 회원 기능을 이용할 수 없다.
2. 활성 회원만 여행, 미션, 저장, 포인트, 배지, 알림, 프로필 기능을 이용할 수 있다.
3. 회원은 자신의 군민증, 포인트, 저장 장소, 여행, 사진, 배지, 설정과 현재 인증 세션의 푸시 토큰만 조회하고 변경할 수 있다.
4. 필수 약관에 동의하지 않은 회원은 군민증 생성과 여행 시작을 할 수 없다.
5. 군민증을 발급받은 회원만 여행을 시작하고 군민증 바코드를 볼 수 있다.
6. 카메라 권한이 없는 회원은 사진 인증을 진행할 수 없다.
7. 알림 권한과 위치 권한이 없는 회원에게는 근처 퀴즈 알림을 제공하지 않는다.
8. 탈퇴한 회원은 모든 회원 기능에 접근할 수 없다.

### 8. 동시 요청 처리

1. 한 회원의 여행 시작 요청이 동시에 여러 번 들어와도 하나의 진행 중 여행만 만든다.
2. 같은 미션의 완료 요청이 동시에 들어와도 완료 이력, 포인트 보상, 연결된 문화재 방문 기록은 한 번만 확정한다.
3. 같은 배지의 획득 처리가 동시에 실행돼도 배지는 한 번만 지급한다.
4. 동일 회원의 포인트 변경은 한 번에 하나만 확정하며, 다음 변경은 직전에 확정된 잔액을 기준으로 처리한다.
5. 같은 여행의 포인트 정산 요청이 동시에 들어오면 가장 먼저 확정된 결과만 인정한다.
6. 같은 장소의 저장과 삭제가 동시에 요청되면 한 요청을 먼저 확정하고 다음 요청은 확정된 상태를 기준으로 처리한다.
7. 탈퇴와 다른 회원 정보 변경이 동시에 요청되면 탈퇴를 우선하고 이후 변경을 거부한다.
8. 같은 FCM 등록 토큰을 여러 인증 세션에서 동시에 등록하면 마지막으로 확정된 활성 세션 하나에만 연결한다.

### 9. 실패 시 롤백 범위

| 행동 | 하나로 처리할 범위 | 실패 시 결과 |
| --- | --- | --- |
| 회원 가입 | 회원 생성, 소셜 계정 연결 | 둘 중 하나라도 실패하면 회원 가입을 완료하지 않는다. |
| 약관 동의 | 선택한 약관의 동의 상태 | 실패한 약관 동의는 반영하지 않고 다시 동의할 수 있게 한다. |
| 군민증 생성 | 표시 이름, 캐릭터, 카드 테마, 군민증 발급 | 하나라도 실패하면 군민증을 발급하지 않는다. |
| 장소 저장·삭제 | 회원과 장소의 저장 관계 | 실패하면 요청 전 저장 상태를 유지한다. |
| 미션 완료 | 완료 이력, 연결된 문화재 방문 기록, 포인트 내역, 포인트 잔액 | 하나라도 실패하면 모두 요청 전 상태로 되돌린다. |
| 배지 획득 | 배지 획득 상태 | 실패하면 미획득 상태를 유지하며 이후 다시 확인할 수 있다. |
| 여행 종료 | 여행 종료 상태 | 실패하면 여행을 진행 중 상태로 유지한다. |
| 포인트 정산 | 정산 결과, 포인트 내역, 포인트 잔액 | 하나라도 실패하면 정산 대기 상태와 기존 포인트를 유지한다. |
| 프로필·서비스 설정 변경 | 변경 대상 정보 | 실패하면 기존 값을 유지한다. |
| 푸시 토큰 등록·삭제 | 현재 인증 세션과 푸시 토큰의 연결 | 실패하면 요청 전 연결 상태를 유지한다. |
| 알림 발송 | 알림 표시 | 알림 실패는 이미 완료된 미션, 포인트, 배지 처리를 되돌리지 않는다. |
| 회원 탈퇴 | 접근 차단, 회원 정보 파기 | 탈퇴 확정 후 접근 차단은 유지하고, 실패한 정보 파기는 완료될 때까지 다시 시도한다. |

## 1. 회원·인증 도메인

### 도메인 모델

#### 회원

부여ON을 이용하는 사람이다. 가입 상태, 프로필, 약관 동의, 군민증, 여행 기록을 가진다.

#### 소셜 계정

회원 가입과 로그인에 사용하는 카카오 또는 Apple(애플) 외부 계정이다.

#### 인증 세션

회원이 현재 로그인한 상태를 나타낸다. 로그아웃하면 종료된다.

#### 푸시 토큰

현재 인증 세션의 기기로 FCM 알림을 보내기 위한 등록 토큰이다. 액세스 JWT의 `sid`로 인증 세션을 식별하며 세션마다 하나만 활성 상태로 관리한다.

### 규칙

1. 가입과 로그인은 카카오 또는 Apple(애플) 소셜 계정을 통해 진행한다.
2. 이미 가입된 소셜 계정은 새 회원을 만들지 않고 기존 회원으로 로그인한다.
3. 신규 회원은 필수 약관 동의를 완료해야 다음 단계로 진행할 수 있다.
4. 로그아웃은 인증 세션만 종료하며 회원 정보와 여행 기록은 유지한다.
5. 탈퇴가 완료되면 로그인할 수 없으며 관련 정보는 안내된 파기 정책에 따라 처리한다.
6. 같은 FCM 등록 토큰이 새 인증 세션에 등록되면 기존 세션에서 새 세션으로 소유권을 옮긴다.
7. 로그아웃하거나 탈퇴하면 해당 인증 세션의 푸시 토큰을 더 이상 발송 대상으로 사용하지 않는다.

## 2. 약관 도메인

### 도메인 모델

#### 약관

서비스 이용약관, 개인정보 처리방침, 마케팅 정보 수신 동의처럼 회원에게 제시하는 정책이다.

#### 약관 동의

회원이 특정 약관의 내용과 적용 버전에 동의했는지를 나타낸다.

### 규칙

1. 서비스 이용약관과 개인정보 처리방침은 필수 약관이다.
2. 마케팅 정보 수신 동의는 선택 약관이며 동의하지 않아도 서비스를 이용할 수 있다.
3. 모든 필수 약관에 동의하기 전에는 다음 단계로 진행할 수 없다.
4. 필수 약관 동의가 끝나면 소셜 계정 연동을 완료하고 군민증 안내로 이동한다.
5. 약관 동의는 어떤 약관의 어떤 버전에 동의했는지 구분할 수 있어야 한다.

## 3. 군민증·프로필 도메인

### 도메인 모델

#### 디지털 군민증

회원이 부여에서 발급받는 임시 시민 자격이다. 표시 이름, 캐릭터, 카드 테마, 발급일, 바코드를 포함한다.

#### 프로필

마이페이지와 군민증에 표시되는 이름과 캐릭터다.

#### 바코드

군민증과 보유 포인트를 제시하는 수단이다. MVP에서는 실제 상점 결제가 아닌 시연 용도로 사용한다.

### 규칙

1. 군민증은 로그인하고 필수 약관에 동의한 회원만 만들 수 있다.
2. 군민증은 회원이 부여 지역 안에 있을 때만 만들 수 있다.
3. 회원은 하나의 활성 군민증만 가진다.
4. 군민증을 만들 때 표시 이름, 프로필 캐릭터, 카드 테마를 모두 선택해야 한다.
5. 표시 이름은 8자 이하여야 한다.
6. 프로필 수정으로 표시 이름과 캐릭터를 변경할 수 있다.
7. 군민증이 없는 회원은 바코드를 볼 수 없다.
8. 바코드는 MVP 시뮬레이션이며 실제 상점에서의 사용은 제한된다.

## 4. 여행 도메인

### 도메인 모델

#### 여행

회원이 부여 안에서 시작해 종료할 때까지의 탐험 단위다. 시작 시각, 종료 시각, 상태와 여행 중 발생한 활동을 가진다.

#### 여행 상태

여행은 `진행 중` 또는 `종료` 상태를 가진다.

### 규칙

1. 여행은 로그인하고 필수 약관에 동의했으며 디지털 군민증을 발급받은 회원만 시작할 수 있다.
2. 여행을 시작할 때 회원의 위치는 부여 지역 안이어야 한다.
3. 한 회원은 동시에 하나의 여행만 진행할 수 있다.
4. 여행 중 발생한 방문, 미션, 포인트, 사진 기록은 해당 여행에 포함된다.
5. 회원이 `부여 떠나기`를 선택하거나 부여 지역을 벗어나면 여행 종료를 제안할 수 있다.
6. 회원이 종료를 취소하면 여행은 계속 진행된다.
7. 진행 중인 여행이 없으면 여행을 종료할 수 없다.
8. 여행이 종료되면 남은 포인트 정산을 진행한다.

## 5. 장소·저장 도메인

### 도메인 모델

#### 장소

사용자가 탐색할 수 있는 부여의 유적지, 식당, 카페다. 이름, 분류, 설명, 위치와 관광 정보를 가진다.

#### 저장한 장소

회원이 나중에 다시 보기 위해 장소를 보관한 관계다.

### 규칙

1. 장소는 유적지, 식당, 카페 중 하나로 분류한다.
2. 장소 조회 시 현재 위치를 기준으로 거리와 예상 도보 시간을 제공한다.
3. 회원은 같은 장소를 한 번만 저장할 수 있다.
4. 이미 저장한 장소를 다시 저장하면 기존 저장 상태를 유지한다.
5. 저장한 장소를 삭제해도 장소 자체와 방문 기록은 삭제되지 않는다.
6. 저장한 장소가 없으면 빈 목록 상태를 제공한다.

## 6. 미션 도메인

### 도메인 모델

#### 미션

특정 장소 근처에서 참여할 수 있는 퀴즈 또는 사진 인증 활동이다. 유형, 위치 조건, 보상 포인트와 참여 조건을 가진다.

#### 미션 참여

회원이 미션에 도전한 상태와 결과다. 도전 가능, 잠김, 완료 상태를 가진다.

### 규칙

1. 미션은 객관식, OX, 사진 인증 유형으로 구분한다.
2. 회원과 미션의 거리가 100m 이내일 때 미션에 참여할 수 있다.
3. 위치 조건을 충족하지 못한 미션은 잠금 상태로 표시한다.
4. 객관식과 OX 미션은 제출한 답의 정답 여부를 표시한다.
5. 사진 인증 미션은 사진을 제출하면 별도 판정 없이 완료로 처리한다.
6. 사진 인증에 필요한 카메라 권한이 없으면 참여 전에 권한 허용을 안내한다.
7. 스페셜 퀴즈는 정해진 도전 기회 안에서만 참여할 수 있다.
8. 일반 퀴즈의 도전 기회는 제한하지 않는다.
9. 완료한 미션에는 보상을 중복 지급하지 않는다.
10. 각 미션은 하나의 문화재 장소와 연결한다. 회원이 미션을 처음 완료하면 해당 여행에 연결된 문화재의 방문 기록을 생성한다.
11. 같은 여행에서 같은 문화재에 연결된 여러 미션을 완료해도 방문 기록은 한 번만 생성한다.

## 7. 포인트 도메인

### 도메인 모델

#### 포인트 잔액

회원이 현재 보유한 부여 포인트다.

#### 포인트 내역

포인트가 언제, 어떤 활동으로 얼마나 변했는지를 나타내는 기록이다.

#### 포인트 정산

여행 종료 후 남은 포인트를 부여에 남기거나 다음 방문까지 유지하는 선택이다.

### 규칙

1. 미션 완료 보상은 회원의 포인트 잔액과 적립 내역에 반영한다.
2. 포인트 적립 내역에는 활동명, 적립 시각, 적립 포인트를 표시한다.
3. 여행 종료 후 해당 여행에서 적립하고 아직 정산하지 않은 포인트가 있으면 정산 방법을 선택한다.
4. `부여에 포인트 남기고 가기`를 선택하면 이번 여행의 정산 대상 포인트는 회원이 더 이상 사용할 수 없고 골목상권 기여로 처리한다. 다른 여행에서 이월한 포인트는 유지한다.
5. `다음에 이어서 쓰기`를 선택하면 이번 여행의 정산 대상 포인트를 정산 완료 시각부터 10×24시간 동안 유지한다.
6. 남은 포인트가 없으면 정산을 건너뛴다.
7. 정산 처리에 실패하면 기존 포인트 상태를 유지한다.
8. MVP의 바코드 표시는 실제 가맹점 포인트 차감을 수행하지 않는다.

## 8. 배지 도메인

### 도메인 모델

#### 배지

탐험, 퀴즈, 기록, 지역상권 활동의 달성을 나타내는 보상이다. 이름, 설명, 달성 조건과 이미지를 가진다.

#### 배지 조건

Spring이 계산하는 메트릭과 달성 임계값의 조합이다. 배지는 하나 이상의 조건을 가진다.

#### 배지 진척도

원본 활동 데이터에서 계산한 각 메트릭의 현재값과 조건 충족 여부다.

#### 획득 배지

회원이 모든 조건을 충족해 받은 배지와 획득 시각의 이력이다. 배지를 처음 획득한 여행과 연결한다.

### 규칙

1. 배지는 하나 이상의 메트릭 조건을 가지며 모든 조건을 충족하면 지급한다.
2. 메트릭은 미션 완료 수, 방문한 고유 문화재 수와 포인트 기부 정산 횟수를 지원한다.
3. 진행도와 상태는 원본 활동 데이터 및 배지 획득 이력으로 계산한다.
4. 같은 배지는 한 회원에게 한 번만 지급하고 획득 상태는 되돌리지 않는다.
5. 지급이 중단된 배지는 새로 지급하지 않지만 기존 획득 이력은 유지한다.
6. 미획득 배지도 각 조건과 현재 진행도를 조회할 수 있다.
7. 배지는 탐험, 퀴즈, 기록, 재화, 특별 분야로 구분한다.
8. 배지를 획득하면 획득을 유발한 여행 ID를 함께 저장하며 이후 다른 여행에서 같은 배지를 다시 연결하지 않는다.

## 9. 알림·설정 도메인

### 도메인 모델

#### 알림

포인트 적립, 배지 획득, 주변 퀴즈, 지역화폐 할인, 군민증 발급, 부여 소식을 회원에게 전달한다.

#### 근처 퀴즈 알림 동의

회원이 유적지 근처의 퀴즈와 한정 미션 알림을 받을지 나타낸다.

#### 푸시 토큰

현재 인증 세션이 사용하는 기기의 FCM 등록 토큰이다.

#### 서비스 설정

GPS 유적지 인근 알림과 다크 모드처럼 회원이 변경할 수 있는 이용 환경이다.

### 규칙

1. 알림은 최근 알림과 지난 알림으로 나누어 조회할 수 있다.
2. 근처 퀴즈 알림은 회원이 동의한 경우에만 제공한다.
3. 근처 퀴즈 알림을 제공하려면 기기의 알림 권한과 위치 권한이 필요하다.
4. 회원이 `다음에 할게요`를 선택하면 기존 알림 설정을 유지한다.
5. 기기 권한이 없으면 알림을 켤 수 없음을 안내한다.
6. 다크 모드 설정은 근처 퀴즈 알림 동의와 독립적으로 변경할 수 있다.
7. 설정 변경에 실패하면 기존 설정을 유지한다.
8. 앱은 알림 권한을 얻고 로그인한 뒤 현재 인증 세션의 푸시 토큰을 서버에 등록한다.
9. 서버는 폐기됐거나 만료된 인증 세션의 푸시 토큰으로 알림을 보내지 않는다.
10. FCM이 토큰 만료 또는 무효를 응답하면 서버는 해당 토큰을 삭제한다.

## 10. 활동·발자취 도메인

### 도메인 모델

#### 방문 기록

회원이 여행 중 미션을 완료해 방문이 확정된 문화재와 방문 시각을 나타낸다. 방문 기록은 여행, 미션, 문화재와 연결한다.

#### 사진 기록

사진 인증 미션에서 회원이 촬영한 여행 사진이며 서버에서 관리한다.

#### 여행 통계

탐방한 문화재 수와 탐방 시간으로 구성된 여행 요약이다. 탐방 시간은 여행 시작부터 종료 시각까지 계산하고, 진행 중에는 현재 시각까지 계산한다. MVP에서는 이동 거리와 소모 칼로리를 계산하지 않고 `null`로 제공한다.

#### 발자취

종료된 여행의 장소, 포인트, 통계, 배지, 사진을 한데 모은 회고 기록이다.

### 규칙

1. 활동 내역에서는 포인트 적립, 사진, 여행 통계, 배지 현황을 조회할 수 있다.
2. 탐방한 문화재 수는 해당 여행의 중복되지 않은 방문 기록 수로 계산한다. 탐방 시간은 종료된 여행은 시작 시각부터 종료 시각까지, 진행 중인 여행은 시작 시각부터 조회 시각까지 계산한다.
3. MVP의 이동 거리와 소모 칼로리는 계산하지 않고 조회 결과에 `null`로 표시한다.
4. 사진 기록은 MVP에서 별도 판정 없이 여행의 추억으로 사용한다.
5. 발자취는 여행이 종료되고 포인트 정산을 마친 후 조회할 수 있다.
6. 발자취에는 방문 장소, 포인트, 이동 거리, 탐방 장소 수, 탐방 시간, 소모 칼로리, 해당 여행에서 처음 획득한 배지와 사진을 포함한다.
7. 여행 기록이 없으면 발자취가 없는 상태를 안내한다.

## 주요 도메인 사건

| 사건 | 발생 조건 | 후속 영향 |
| --- | --- | --- |
| 회원 가입 완료 | 신규 소셜 계정으로 가입 | 필수 약관 동의가 필요해진다. |
| 필수 약관 동의 완료 | 모든 필수 약관에 동의 | 계정 연동과 군민증 안내로 진행한다. |
| 군민증 발급 | 부여 안에서 군민증 정보를 모두 선택 | 여행을 시작할 수 있다. |
| 여행 시작 | 시작 조건을 충족하고 여행 시작 선택 | 방문·미션·사진·포인트 활동을 여행에 기록한다. |
| 장소 저장 | 장소 상세에서 저장 선택 | 저장한 장소 목록에 반영한다. |
| 미션 완료 | 미션별 완료 조건 충족 | 연결된 문화재 방문 기록을 생성하고 포인트를 적립한 뒤 배지 조건을 확인한다. |
| 배지 획득 | 배지 조건 충족 | 획득 배지와 알림에 반영한다. |
| 여행 종료 | 회원이 여행 끝내기를 확인 | 포인트 정산을 시작한다. |
| 포인트 정산 완료 | 포인트 남기기 또는 유지 선택 | 발자취를 조회할 수 있다. |
