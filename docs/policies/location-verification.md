# 위치 인증

1. 군민증 생성과 여행 시작은 현재 위치가 부여 행정구역 안에 있을 때만 허용한다.
2. 주변 미션 탐색은 현재 GPS 위치와 미션 위치 사이의 직선거리가 500m 이내인 미션을 대상으로 하며 경계를 포함한다.
3. 미션 참여는 현재 GPS 위치와 미션 위치 사이의 직선거리가 30m 이내일 때만 허용하며 경계를 포함한다.
4. 부여 행정구역 밖으로 이동한 사실만으로 여행을 즉시 종료하지 않고 회원의 종료 확인을 받는다.
5. 위치 권한이 없거나 현재 위치를 확인할 수 없으면 위치 인증이 필요한 행동을 허용하지 않는다.
6. 위치 재확인은 기존 위치가 아니라 새로 확인한 현재 위치를 기준으로 판단한다.
7. 저장 목록, 포인트 내역, 배지, 발자취 조회에는 위치 인증을 요구하지 않는다.
8. 부여 행정구역은 [국토교통부 법정구역정보](https://www.data.go.kr/data/15045881/fileData.do)의 시군구(`SIG`) 전체 데이터에서 부여군 코드 `44760`을 추출한 GeoJSON Polygon 또는 MultiPolygon으로 고정한다.
9. GeoJSON과 별도 메타데이터에는 원본 URL, 부여군 코드, 추출일, 좌표계와 GeoJSON 파일의 SHA-256을 기록하고 함께 버전 관리한다.
10. 군민증 생성과 여행 시작 시 서버는 전달받은 위치가 이 Polygon 내부 또는 경계 위에 있는지 판정하며 요청 처리 중 외부 지오코딩·경계 API에 의존하지 않는다.
11. MVP API는 유효 범위의 클라이언트 좌표를 요청 시점의 현재 위치로 간주한다. `capturedAt`은 요청 기록용이며 서버가 별도 신선도 제한을 적용하지 않는다.
12. 위치 권한 거부와 GPS 획득 실패는 앱이 요청 전에 처리하며 좌표 위·변조 방지와 GPS 정확도 제한은 범위에서 제외한다.
13. 거리 응답은 가장 가까운 정수 m로 반올림할 수 있지만 위치 조건은 반올림 전 직선거리로 판정한다.
