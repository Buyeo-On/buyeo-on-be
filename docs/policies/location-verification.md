# 위치 인증

1. 군민증 생성과 여행 시작은 현재 위치가 부여 행정구역 안에 있을 때만 허용한다.
2. 미션 참여는 현재 GPS 위치와 미션 위치 사이의 직선거리가 100m 이내일 때만 허용한다.
3. 부여 행정구역 밖으로 이동한 사실만으로 여행을 즉시 종료하지 않고 회원의 종료 확인을 받는다.
4. 위치 권한이 없거나 현재 위치를 확인할 수 없으면 위치 인증이 필요한 행동을 허용하지 않는다.
5. 위치 재확인은 기존 위치가 아니라 새로 확인한 현재 위치를 기준으로 판단한다.
6. 저장 목록, 포인트 내역, 배지, 발자취 조회에는 위치 인증을 요구하지 않는다.
7. 부여 행정구역은 서버 애플리케이션에 포함된 버전 관리 대상 GeoJSON Polygon으로 고정한다.
8. 군민증 생성과 여행 시작 시 서버는 전달받은 위치가 이 Polygon 내부 또는 경계 위에 있는지 판정하며 외부 지오코딩 API에 의존하지 않는다.
