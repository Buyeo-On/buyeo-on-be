# 트랜잭션과 실패 시 롤백

| 행동 | 하나로 처리할 범위 | 실패 시 결과 |
| --- | --- | --- |
| 회원 가입 | 회원 생성, 소셜 계정 연결, 기본 서비스 설정 생성 | 하나라도 실패하면 회원 가입과 인증 세션 발급을 완료하지 않는다. |
| 로그인 | 소셜 계정 확인, 인증 세션 발급 | 인증 세션 저장에 실패하면 서비스 토큰을 발급하지 않는다. |
| 토큰 갱신 | 기존 리프레시 토큰 확인, 새 토큰 해시 저장 | 교체에 실패하면 새 서비스 토큰을 발급하지 않는다. |
| 로그아웃 | 현재 인증 세션 폐기, 연결된 푸시 토큰 삭제 | 하나라도 실패하면 세션과 토큰 연결을 요청 전 상태로 되돌린다. |
| 약관 동의 | 선택한 약관의 동의 상태 | 실패한 약관 동의는 반영하지 않고 다시 동의할 수 있게 한다. |
| 군민증 생성 | 회원 프로필, 캐릭터, 카드 테마, 군민증 발급, 성공 멱등성 기록 | 하나라도 실패하면 프로필, 군민증과 멱등성 기록을 요청 전 상태로 되돌린다. |
| 여행 시작 | 여행 생성, 성공 멱등성 기록 | 하나라도 실패하면 여행 생성과 멱등성 기록을 요청 전 상태로 되돌린다. |
| 장소 저장·삭제 | 회원과 장소의 저장 관계 | 실패하면 요청 전 저장 상태를 유지한다. |
| 미션 완료 | 완료 이력, 연결된 문화재 방문 기록, 포인트 내역, 포인트 잔액, 새 배지 획득 이력, `BADGE` 알림 | 하나라도 실패하면 모두 요청 전 상태로 되돌린다. |
| 배지 reconciliation | 회원 한 명의 새 배지 획득 이력과 `BADGE` 알림 | 하나라도 실패하면 해당 회원의 이번 reconciliation 지급을 반영하지 않고 다음 실행에서 다시 판정한다. |
| 여행 종료 | 여행 종료 상태 | 실패하면 여행을 진행 중 상태로 유지한다. |
| 포인트 정산 | 정산 결과, 포인트 내역, 포인트 잔액, 새 배지 획득 이력, `BADGE` 알림 | 하나라도 실패하면 정산 대기 상태와 기존 포인트를 유지한다. |
| 이월 포인트 만료 | 만료 처리 상태, `EXPIRE` 포인트 내역과 포인트 잔액 | 하나라도 실패하면 만료 처리를 확정하지 않고 다음 실행에서 다시 시도한다. |
| 프로필·서비스 설정 변경 | 변경 대상 정보 | 실패하면 기존 값을 유지한다. |
| 푸시 토큰 등록·삭제 | 현재 인증 세션과 푸시 토큰의 연결 | 실패하면 요청 전 연결 상태를 유지한다. |
| FCM push 발송 | 외부 push 전달 | FCM 실패는 이미 저장한 activity, 배지와 persistent 알림을 되돌리지 않는다. |
| 회원 탈퇴 확정 | 탈퇴 상태·파기 기한 기록, 모든 인증 세션 폐기, 모든 푸시 토큰과 소셜 계정 연결 삭제 | 하나라도 실패하면 회원 상태와 세션·푸시 토큰·소셜 계정 연결을 요청 전 상태로 되돌린다. |
| 탈퇴 회원 정보 파기 | S3 사진 객체 삭제 후 파기 대상 관계형 데이터와 회원 행 삭제 | 탈퇴 접근 차단은 유지한다. 객체 또는 DB 삭제가 실패하면 탈퇴 회원 행을 유지하고 다음 정기 작업에서 다시 시도한다. |
