# 날짜와 시간대

1. 서비스의 날짜와 시간 판단 기준은 한국 표준시 `Asia/Seoul`이다.
2. `오늘`은 한국 표준시 00:00부터 다음 날 00:00 전까지다.
3. 여행 시작·종료, 방문, 미션 완료, 포인트 적립, 배지 획득, 알림 발생 시각은 해당 행동이 확정된 시각으로 기록한다.
4. 목록 정렬과 화면 표시는 한국 표준시 기준의 발생 시각을 사용한다.
5. `다음에 이어서 쓰기`를 선택한 포인트는 정산 완료 시각부터 `10×24시간` 동안 유효하다.
6. 이월 포인트는 유효기간 종료 시각부터 만료 대상으로 보며, 멱등한 정기 작업이 만료 내역을 생성한다.
7. 유효기간의 종료 시각은 한국 표준시로 표시한다.
8. 실시간 배지 획득 시각은 획득을 유발한 activity의 확정 시각이다.
9. 과거 활동을 reconciliation해 지급한 배지의 획득 시각은 reconciliation에서 지급을 확정한 시각이다.
10. 여행 포인트 정산은 잠금 획득 후 DB에서 한 번 구한 시각을 정산, 여행 상태 전이, 포인트 내역, 신규 배지, 배지 알림과 멱등성 semantic result에 함께 사용한다.
11. 이월 만료의 `EXPIRE` 포인트 내역은 약속된 만료 시각을 발생 시각으로 기록하고, 별도의 실제 처리 완료 시각을 정산에 기록한다.

애플리케이션은 `Instant`, DB는 `timestamptz`, 서버와 DB 시스템 시간대는 UTC를 사용한다. 사용자 표시와 날짜 판정만 `Asia/Seoul`로 변환한다.
