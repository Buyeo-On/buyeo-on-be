# 삭제 정책

1. 로그아웃은 인증 세션만 종료하며 회원, 군민증, 포인트, 여행 기록을 삭제하지 않는다.
2. 저장한 장소 삭제는 회원과 장소의 저장 관계만 삭제하며 장소 정보와 방문 기록은 유지한다.
3. 회원 탈퇴가 확정되면 즉시 로그인을 차단한다.
4. 탈퇴 회원의 프로필, 군민증, 위치·여행·미션·사진·포인트·저장·배지·알림 설정·푸시 토큰 정보는 탈퇴 후 30일 이내에 파기한다.
5. 사진 인증 이미지는 서버에서 관리하며 해당 회원, 여행, 미션 기록과 연결한다.
6. 삭제 작업 일부가 실패해도 탈퇴 회원의 접근 권한을 복구하지 않고 삭제를 다시 시도한다.
7. 탈퇴 회원의 S3 사진 객체를 먼저 삭제하고 객체 삭제가 모두 성공한 경우에만 연결된 관계형 데이터를 삭제한다.
8. 탈퇴 상태와 재가입 금지를 판정하는 최소 회원·소셜 계정 연결 이력은 서비스 이용 데이터 파기 대상에서 제외하며, 보유 목적과 기간을 개인정보 처리방침에 고지한다.
9. 파기 기한이 지난 회원 정보는 멱등한 정기 작업으로 반복 처리한다. 이미 삭제된 객체나 행의 재삭제는 성공으로 취급한다.
10. 파기 대상 관계형 데이터 삭제가 완료되면 최소 회원 이력에 파기 완료 시각을 기록하고 이후 정기 처리 대상에서 제외한다.
