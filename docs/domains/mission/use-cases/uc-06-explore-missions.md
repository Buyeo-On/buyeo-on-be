# 미션 탐색

## 목적

사용자는 현재 위치 근처의 퀴즈와 사진 인증 미션을 지도에서 탐색하고 현장에서 참여할 미션의 상세를 확인한다.

## 사전 조건

- 사용자가 활성 회원으로 로그인한 상태다.
- 사용자가 소유한 진행 중 여행이 존재한다.
- 앱이 현재 위치의 위도와 경도를 확인했다.
- 장소와 미션 예시 카탈로그가 Flyway 시드로 적재되어 있다.

## 기본 흐름

1. 사용자가 현재 위치와 진행 중인 여행 ID로 주변 미션을 조회한다.
2. 서버는 현재 위치에서 직선거리 500m 이내인 OX·객관식·사진 인증 미션을 모두 조회한다. 경계인 500m를 포함한다.
3. 완료·기회 소진 상태를 포함해 반올림 전 실제 거리 오름차순, 실제 거리가 같으면 미션 ID 오름차순으로 반환한다. 같은 장소의 여러 미션은 각각 반환한다.
4. 완료 또는 기회 소진 기록이 없는 미션은 직선거리 100m 이하면 `AVAILABLE`, 100m를 초과하면 `LOCKED`로 표시한다. 경계인 100m는 참여할 수 있다.
5. 완료와 기회 소진 상태는 위치가 바뀌어도 각각 `COMPLETED`, `EXHAUSTED`로 유지한다.
6. 목록에는 미션과 여행·장소 식별자, 유형, 제목, 장소명, 좌표, 표시용 거리, 보상, 표시 상태, 참여 반경과 남은 도전 횟수를 제공한다.
7. 사용자가 미션을 선택하면 위치와 관계없이 상세를 조회할 수 있다. 현재 거리가 100m 이내면 문제 또는 촬영 안내와 객관식 선택지를 포함한 전체 상세를 반환한다.
8. 현재 거리가 100m를 초과하면 상태와 관계없이 목록과 같은 제한 상세만 반환하고 문제, 촬영 안내와 객관식 선택지는 반환하지 않는다.

## 예외 흐름

- 좌표나 식별자 형식이 잘못되면 `400 INVALID_REQUEST`를 반환한다.
- 인증되지 않았거나 활성 인증 세션이 아니면 `401 UNAUTHORIZED`를 반환한다.
- 여행이 없거나 다른 회원의 여행이면 존재 여부를 구분하지 않고 `404 RESOURCE_NOT_FOUND`를 반환한다.
- 본인 여행이지만 종료 또는 정산 상태면 `409 TRIP_NOT_IN_PROGRESS`를 반환한다.
- 미션 상세 대상이 없으면 `404 RESOURCE_NOT_FOUND`를 반환한다.
- 500m 안에 미션이 없으면 빈 목록을 정상 반환한다.
- 네트워크 연결 실패는 서버 응답이 아니며 앱이 안내하고 재시도한다.

## 상태와 횟수 계산

- 조회는 미션 참여 행을 생성하거나 위치 기반 상태를 저장하지 않는다.
- 참여 기록이 없으면 도전 횟수는 0으로 간주한다.
- 표시 상태는 `COMPLETED`, `EXHAUSTED`, 현재 거리 기반 `AVAILABLE` 또는 `LOCKED` 순으로 결정한다.
- 일반 퀴즈와 사진 인증 미션의 남은 도전 횟수는 `null`이다.
- 스페셜 퀴즈가 도전 가능하면 최대 횟수에서 사용 횟수를 뺀 값을 반환하고, 완료 또는 기회 소진 상태면 0을 반환한다.
- 도전 가능한(완료·기회 소진이 아닌) 스페셜 퀴즈는 여행 ID·KST 날짜·미션 ID로 정해지는 시드로 하루 20%만 노출한다. 노출 대상이 아니면 목록에서 제외되고 상세 조회도 `404`를 반환한다. 완료·기회 소진된 스페셜 퀴즈와 일반 퀴즈·사진 인증 미션은 이 노출 판정과 무관하게 항상 노출된다.
- API의 정수 거리는 가장 가까운 m로 반올림하지만 100m 참여 및 500m 탐색 판정은 반올림 전 거리를 사용한다.

## 동시성과 실패 복구

- 조회는 상태를 변경하지 않으므로 멱등성 키와 별도 롤백이 필요하지 않다.
- 여행 종료와 조회가 동시에 발생하면 조회가 관찰한 일관된 DB 시점을 기준으로 처리한다. 여행 종료가 먼저 관찰되면 `409`, 조회가 먼저 관찰되면 해당 응답을 완료한다.
- DB 조회 실패 시 부분 목록을 반환하지 않고 요청 전체가 실패한다.

## 범위 제외

- 클라이언트가 전달한 유효한 좌표를 MVP의 현재 위치로 간주하며 좌표 위·변조 방지는 다루지 않는다.
- 지도 뷰포트 검색, 페이지네이션과 사용자 지정 탐색 반경은 다루지 않는다.
- 관리자 API, CMS, 미션 초안·비활성·게시 기간과 예시 시드를 대체할 정식 운영 콘텐츠 관리·갱신 절차는 다루지 않는다. MVP 운영에도 버전 관리되는 예시 시드를 임시 적용한다.
- 미션 제출, 정답 판정, 사진 업로드와 보상 지급은 [UC-09 퀴즈 풀이](./uc-09-complete-mission.md)의 범위다.
