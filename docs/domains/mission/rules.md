# 미션 도메인 모델과 규칙

## 책임

장소에 연결된 미션 정의, 위치 조건, 답안·사진 제출, 도전 기회와 완료 기록을 소유한다.

## 모델

### 미션

특정 장소 근처에서 참여할 수 있는 퀴즈 또는 사진 인증 활동이다. 유형, 위치 조건, 보상 포인트와 참여 조건을 가진다.

### 미션 참여

회원이 여행 중 미션에 도전한 상태와 결과다.

### 사진 기록

사진 인증 미션에서 회원이 촬영한 여행 사진이며 서버에서 관리한다. 회원, 여행과 미션에 연결한다.

## 규칙

1. 미션은 객관식, OX와 사진 인증 유형으로 구분한다.
2. 주변 미션 탐색은 회원의 현재 위치와 미션이 연결된 장소의 직선거리가 500m 이내인 미션을 대상으로 하며 경계를 포함한다.
3. 회원과 미션의 거리가 100m 이내일 때 미션에 참여할 수 있으며 경계를 포함한다.
4. API 표시 상태는 완료, 기회 소진, 위치 순으로 판정한다. 완료 또는 기회 소진이 아니면서 100m를 초과한 미션은 `LOCKED`, 100m 이내인 미션은 `AVAILABLE`로 표시한다.
5. `LOCKED`는 현재 위치에서 파생하는 API 표시 상태이며 미션 참여에 저장하지 않는다.
6. 미션 탐색과 상세 조회는 미션 참여를 생성하거나 상태를 변경하지 않는다. 참여 기록이 없으면 도전 횟수 0으로 조회한다.
7. 100m 이내에서는 문제 또는 촬영 안내와 객관식 선택지를 포함한 전체 상세를 제공한다. 100m를 초과하면 완료·기회 소진 여부와 관계없이 목록과 같은 제한 상세만 제공한다.
8. 객관식과 OX 중 최대 도전 횟수가 있는 미션을 스페셜 퀴즈라고 한다. 사진 인증 미션에는 최대 도전 횟수를 두지 않는다.
9. 일반 퀴즈의 도전 기회는 제한하지 않는다.
10. 스페셜 퀴즈의 남은 도전 횟수는 도전 가능한 동안 최대 횟수에서 사용 횟수를 뺀 값이며 완료 또는 기회 소진 후에는 0이다. 일반 퀴즈와 사진 인증 미션은 `null`이다.
11. 객관식과 OX 미션은 제출한 답의 정답 여부를 표시한다.
12. 사진 인증 미션은 사진을 제출하면 별도 판정 없이 완료로 처리한다.
13. 사진 인증에 필요한 카메라 권한이 없으면 참여 전에 권한 허용을 안내한다.
14. 스페셜 퀴즈는 정해진 도전 기회 안에서만 참여할 수 있다.
15. 완료한 미션에는 보상을 중복 지급하지 않는다.
16. 각 미션은 하나의 문화재 장소와 연결한다.
17. 회원이 미션을 처음 완료하면 해당 여행에 연결된 문화재의 방문 기록을 생성한다.
18. 같은 여행에서 같은 문화재에 연결된 여러 미션을 완료해도 방문 기록은 한 번만 생성한다.
19. MVP에서는 DB에 저장된 모든 미션 정의를 게시된 상태로 간주하며 초안, 비활성화와 게시 기간을 구분하지 않는다.
20. 미션을 완료하면 `MissionCompleted` 이벤트를 발행한다. 리스너가 없어도 발행 자체는 완료 처리에 영향을 주지 않는다.
21. 미션 완료 처리는 badge의 공개 application service를 동기 호출해 `MISSION_COMPLETED_COUNT`를 판정하고, 방문 기록을 새로 만들었으면 `HERITAGE_VISITED_COUNT`도 함께 판정한다. 새로 지급된 배지는 제출 response에 포함한다.

## 상태 전이

| 모델 | 허용 상태 전이 | 규칙 |
| --- | --- | --- |
| 미션 참여 | 도전 가능 → 기회 소진 또는 완료 | 영속 상태는 `AVAILABLE`, `EXHAUSTED`, `COMPLETED`이며 완료와 기회 소진은 되돌리지 않는다. |
| API 표시 상태 | 잠김 ↔ 도전 가능 | 영속 참여 상태가 도전 가능일 때만 현재 위치에 따라 `LOCKED`와 `AVAILABLE` 사이에서 바뀐다. |
