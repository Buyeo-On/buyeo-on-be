# 군민증과 바코드 보기

## 목적

사용자가 발급된 디지털 군민증을 확인하고 MVP 시연용 바코드와 현재 포인트 잔액을 확인한다.

## 사전 조건

- 사용자가 로그인 상태다.
- 사용자가 디지털 군민증을 발급받았다.

## 기본 흐름

1. 앱은 내 군민증을 조회한다.
2. 서버는 현재 프로필의 표시 이름·캐릭터와 발급 시 선택한 카드 테마를 조합하고 각각 10분 유효한 이미지 URL을 발급한다.
3. 앱은 발급 시각과 함께 군민증 화면을 표시한다.
4. 사용자가 탐험 화면 또는 활동 내역에서 `군민증 바코드`를 누른다.
5. 서버는 같은 군민증과 바코드 값, 조회 시점의 포인트 원장 합계를 반환하며 포인트를 변경하지 않는다.
6. 앱이 디지털 군민증, 바코드, 보유 포인트와 실제 상점 사용 제한 안내를 표시한다.
7. 사용자가 바코드를 확인하거나 MVP 시연에 사용한 뒤 화면을 닫는다.

## 예외 흐름

- 인증하지 않았거나 세션이 무효하면 `401 UNAUTHORIZED`를 반환한다.
- 군민증이 없으면 `404 RESOURCE_NOT_FOUND`를 반환하고 앱은 군민증 생성을 안내한다.
- 포인트 내역이 없으면 잔액은 `0`이다.
- 이미지 URL이나 조회 응답을 불러오지 못하면 앱은 다시 시도하도록 안내한다.

## 범위 경계

- `GET /citizen-cards/me`와 `GET /citizen-cards/me/barcode`를 이 유즈케이스가 소유한다.
- 군민증 생성과 선택지 조회는 UC-04가 소유한다.
- 바코드 조회는 포인트를 차감하거나 포인트 내역을 만들지 않는다.
- 바코드를 이용한 결제, 가맹점 검증과 실제 지역화폐 연동은 범위에서 제외한다.
