# 로그인

## 목적

사용자가 소셜 계정으로 인증해 기존 회원으로 로그인하거나 신규 회원을 만들고, 현재 온보딩 상태를 확인한다.

## 사전 조건

- 사용자가 로그인 화면에 진입한 상태다.
- 사용자가 인터넷에 연결되어 있다.

## 기본 흐름

1. 사용자가 `카카오로 시작하기` 또는 `Apple로 시작하기` 버튼을 누른다.
2. 시스템이 선택한 소셜 로그인 화면을 제공한다.
3. 사용자가 카카오 또는 Apple 계정으로 로그인하고 필요한 정보 제공에 동의한다.
4. 서버가 제공자에게 인증 정보를 검증하고 제공자 회원 식별자를 확인한다.
5. 이미 연결된 활성 회원이면 새 인증 세션을 만들고 로그인한다.
6. 연결된 회원이 없으면 회원, 소셜 계정과 기본 서비스 설정을 하나의 트랜잭션으로 만들고 새 인증 세션을 발급한다.
   - 탈퇴 시 삭제된 소셜 계정 연결로 다시 로그인한 경우에도 별도의 신규 회원을 만들며 탈퇴 전 회원이나 이용 데이터를 복구하지 않는다.
7. 앱은 응답의 필수 약관 동의 여부와 군민증 발급 여부를 기준으로 다음 화면을 선택한다.
   1. 필수 약관 미동의: 약관 동의 화면
   2. 필수 약관 동의 완료, 군민증 미발급: 위치 확인 및 군민증 안내 화면
   3. 군민증 발급 완료: 기존 회원 복귀 화면에서 군민증과 누적 기록을 확인한 뒤 탐험 또는 여행 시작 화면

## 예외 흐름

- 같은 소셜 계정의 가입 요청이 동시에 처리되면 회원은 하나만 만들고 각 요청에 별도 인증 세션을 발급한다.
- 소셜 인증 정보가 유효하지 않거나 만료됐으면 인증 실패를 안내한다.
- 소셜 제공자 장애로 검증할 수 없으면 일시적인 서비스 오류를 안내하고 회원이나 세션을 만들지 않는다.
- 유효하지 않거나 만료·폐기·이미 회전된 리프레시 토큰으로 갱신하면 인증 실패를 반환한다.
- 네트워크 연결에 실패하면 네트워크 오류를 안내한다.
- 사용자가 정보 제공에 동의하지 않으면 로그인을 중단한다.

## 범위 경계

- 로그인 성공 응답은 회원과 온보딩 상태까지만 제공한다. 진행 중 여행은 `GET /trips/current`로 별도 조회한다.
- 다른 소셜 계정 연결은 `POST /members/me/social-accounts`, 로그아웃은 UC-22에서 다룬다.
- UC-02는 이 유즈케이스와 UC-03, UC-04를 연결해 신규 회원 온보딩 전체 흐름을 검증하는 통합 시나리오다.
