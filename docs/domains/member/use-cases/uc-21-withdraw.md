# 탈퇴

## 목적

사용자가 부여ON 회원 자격을 종료한다.

## 사전 조건

- 사용자가 활성 회원의 유효한 인증 세션으로 로그인한 상태다.

## 기본 흐름

1. 사용자가 마이페이지에서 `회원탈퇴`를 누른다.
2. 앱이 탈퇴 시 삭제되는 정보와 유의사항을 안내한다.
3. 사용자가 탈퇴를 확정한다.
4. 시스템은 회원 행을 잠그고 회원을 `WITHDRAWN`으로 전환하며 탈퇴 확정 시각과 30일 뒤 파기 기한을 기록한다.
5. 시스템이 같은 트랜잭션에서 회원의 모든 인증 세션을 폐기하고 모든 푸시 토큰을 삭제한다.
6. 앱이 탈퇴 완료 응답을 받으면 로컬 액세스·리프레시 토큰을 삭제하고 로그인 화면으로 이동한다.

## 정보 파기

- 탈퇴 확정과 정보 파기는 분리한다. 탈퇴 API는 즉시 접근을 차단하고 정보 파기를 기다리지 않고 성공한다.
- 서버의 멱등한 정기 작업은 파기 기한이 지난 탈퇴 회원을 조회해 프로필, 군민증, 약관 동의, 인증 세션, 설정, 여행, 미션 사진·제출, 포인트, 저장 장소, 배지와 알림 데이터를 삭제한다.
- 미션 사진은 S3 객체 삭제가 모두 성공한 뒤 관계형 데이터를 삭제한다. 객체 삭제나 DB 삭제가 일부 실패하면 회원 접근 차단을 유지하고 다음 실행에서 다시 시도한다.
- 관계형 데이터 삭제를 완료하면 회원 최소 이력에 `purged_at`을 기록한다. 정기 작업은 `purged_at`이 없는 회원만 처리한다.
- 재가입과 계정 복구를 막는 최소 탈퇴 이력인 회원 상태와 소셜 계정 연결은 파기 대상에서 제외한다. 이 정보의 보유 목적과 기간은 개인정보 처리방침에 고지한다.

## 예외 흐름

- 사용자가 취소하면 마이페이지로 돌아간다.
- 인증하지 않았거나 세션이 만료·폐기됐으면 `401 UNAUTHORIZED`를 반환한다.
- 탈퇴 확정 트랜잭션이 실패하면 회원 상태와 세션을 요청 전 상태로 되돌리고 오류를 안내한다.
- 성공 응답을 받지 못해 같은 액세스 토큰으로 다시 요청하더라도 이미 탈퇴가 확정됐다면 세션 검증 단계에서 `401 UNAUTHORIZED`를 반환한다. 앱은 이를 로그아웃 상태로 처리한다.

## 동시성과 멱등성

- `DELETE /members/me`는 `Idempotency-Key`를 요구하지 않는다. 성공 즉시 인증 세션이 폐기되므로 인증 이후 성공 응답을 재생하는 일반 멱등성 저장소를 사용할 수 없다.
- 같은 회원의 탈퇴 요청이 동시에 인증 단계를 통과하면 회원 행 잠금으로 직렬화하며, 첫 요청만 상태를 전환하고 뒤 요청은 탈퇴 상태를 확인한 뒤 성공으로 종료한다.
- 탈퇴와 프로필·설정·푸시 토큰 등 회원 정보 변경이 경합하면 모두 회원 행을 먼저 잠그고, 탈퇴가 확정된 뒤의 변경을 거부한다.

## 범위 경계

- 앱의 확인 모달, 안내 문구와 로컬 토큰 삭제는 Flutter가 담당한다.
- 탈퇴한 소셜 계정의 로그인·재가입 거부는 UC-01이 소유한다.
- 정보 파기는 ADR-010에 따라 별도 워커 없이 Spring Scheduler로 실행한다.
