# 서비스 설정

## 목적

사용자가 여행 중 필요한 알림과 화면 표시 방식을 설정한다.

## 사전 조건

- 사용자가 로그인 상태다.

## 기본 흐름

1. 사용자가 `마이페이지`에 진입한다.
2. 앱이 현재 서비스 설정과 버전을 조회한다.
3. 사용자가 GPS 유적지 인근 알림 또는 다크 모드 설정을 변경한다.
4. 근처 퀴즈 알림을 켜는 경우 앱은 기기의 알림·위치 권한을 확인한다.
5. 앱이 조회한 버전과 변경한 설정만 제출한다.
6. 시스템이 설정을 변경하고 현재 설정과 새 버전을 반환한다.
7. 앱이 반환된 설정을 적용하고 현재 상태를 표시한다.

## 예외 흐름

- 기기 권한이 꺼져 있으면 권한 설정이 필요함을 안내한다.
- 다른 기기나 요청이 설정을 먼저 변경했으면 최신 설정을 다시 조회해 사용자 변경을 재적용한다.
- 설정 변경에 실패하면 기존 설정을 유지하고 오류를 안내한다.

## 범위 경계

- `nearbyQuizNotificationEnabled` 필드는 UI상 "근처 퀴즈 알림"이지만, MVP에서는 알림 유형별 동의 필드가 따로 없어 이 필드 하나가 push를 발송하는 모든 알림 유형(부여 진입 등)의 동의 여부를 함께 결정한다. 자세한 내용은 [알림 도메인 규칙](../../notification/rules.md)을 참고한다.
