# 로그아웃

## 목적

사용자가 현재 기기에서 로그인 상태를 종료한다.

## 사전 조건

- 사용자가 로그인 상태다.

## 기본 흐름

1. 사용자가 마이페이지에서 `로그아웃`을 누른다.
2. 앱이 로그아웃 여부를 다시 확인한다.
3. 사용자가 로그아웃을 확정한다.
4. 앱이 현재 액세스 토큰으로 로그아웃을 요청한다.
5. 시스템이 JWT의 `sid`에 해당하는 현재 인증 세션을 폐기하고 연결된 푸시 토큰을 삭제한다.
6. 앱이 메모리의 액세스 토큰과 Secure Storage의 리프레시 토큰을 삭제하고 로그인 화면으로 이동한다.

## 예외 흐름

- 사용자가 취소하면 마이페이지로 돌아간다.
- 인증하지 않았거나 현재 세션이 이미 만료·폐기됐으면 `401 UNAUTHORIZED`를 반환하며 다른 세션과 회원 데이터는 변경하지 않는다.
- 세션 폐기나 푸시 토큰 삭제에 실패하면 모두 요청 전 상태로 되돌리고 로그인 상태를 유지한다.

## 동시 요청

- 로그아웃과 현재 리프레시 토큰 갱신은 같은 인증 세션 행을 잠가 직렬화한다.
- 갱신이 먼저 확정되더라도 이어서 로그아웃이 세션을 폐기하므로 새로 발급된 토큰은 더 이상 사용할 수 없다.
- 로그아웃이 먼저 확정되면 리프레시 토큰 갱신은 `401 UNAUTHORIZED`다.

## 범위 경계

- 로그아웃은 현재 JWT의 `sid` 세션에만 적용하며 같은 회원의 다른 기기 인증 세션은 유지한다.
- 회원, 소셜 계정, 약관 동의, 군민증, 프로필, 설정, 여행, 장소, 미션, 포인트와 배지 데이터는 삭제하지 않는다.
- 같은 액세스 토큰으로 로그아웃을 다시 요청하면 이미 폐기된 세션이므로 `401 UNAUTHORIZED`다.
- 모든 기기 세션 폐기와 개인정보 파기는 UC-21 회원 탈퇴가 소유한다.
