# 약관 동의

## 목적

사용자는 공개된 법정 고지 문서를 확인하고 필요한 시점에 현재 버전의 동의 상태를 저장한다.

## 사전 조건

- 약관 목록은 로그인하지 않아도 조회할 수 있다.
- 약관 동의 저장은 활성 회원의 유효한 인증 세션이 필요하다.
- 가입 단계에서는 현재 서비스 이용약관에 동의하지 않은 상태다.
- 위치 동의는 사용자가 처음 위치기반 기능을 선택한 시점에 별도로 받는다.

## 기본 흐름

1. 앱은 약관 종류별로 현재 시각에 유효한 버전 하나씩을 조회한다.
2. 사용자는 현재 약관의 제목과 본문을 확인한다.
3. 가입 단계에서 사용자는 만 14세 이상임을 확인하고 서비스 이용약관에 동의한다. 개인정보 처리방침은 동의 체크박스가 아닌 열람 문서로 제공한다.
4. 위치기반 기능을 처음 선택하면 앱은 현재 위치기반서비스 이용약관과 개인위치정보 이용 내용을 보여주고 동의 또는 나중에를 선택하게 한다.
5. 앱은 이번 화면에서 결정한 현재 약관의 `termId`, `version`, `agreed`만 `Idempotency-Key`와 함께 전송한다.
6. 서버는 제출한 각 약관이 공개된 현재 버전과 일치하고 필수 약관을 거부하지 않았는지 확인한다.
7. 서버는 요청에 포함된 동의 상태를 하나의 트랜잭션으로 저장하고 현재 필수 약관 전체 동의 여부와 확정 시각을 응답한다.
8. 같은 회원이 최초 성공 후 24시간 안에 같은 멱등성 키와 같은 본문으로 재시도하면 최초 성공 응답을 반환한다.
9. 가입 동의 저장이 끝나면 군민증이 없는 회원은 UC-04로, 이미 군민증이 있는 재동의 회원은 탐험 화면으로 이동한다.

## 예외 흐름

- 요청이 비어 있거나 같은 약관을 중복해 제출하면 `400`을 반환하고 기존 동의를 변경하지 않는다.
- 필수 약관을 `agreed: false`로 제출하면 `400`을 반환하고 군민증 안내로 진행하지 않는다.
- 사용자가 약관을 보는 동안 새 버전이 시행되었거나 `termId`와 `version`이 현재 약관과 일치하지 않으면 `409 TERM_VERSION_OUTDATED`를 반환한다. 앱은 약관 목록을 다시 조회한다.
- 같은 멱등성 키를 다른 본문이나 작업에 재사용하면 `409 IDEMPOTENCY_KEY_REUSED`를 반환한다.
- 인증하지 않았거나 세션이 무효하면 `401`을 반환한다.
- 동의 저장 중 하나라도 실패하면 전체 요청을 롤백하고 요청 전 상태를 유지한다.
- 네트워크 응답을 확인하지 못하면 앱은 같은 멱등성 키와 본문으로 재시도한다.

## 범위 경계

- `GET /terms`는 공개 API이며 공개 상태인 약관 종류별 현재 버전만 반환한다.
- `GET /members/me/term-consents`는 인증 회원에게 공개된 현재 약관별 본인 동의 여부를 반환한다.
- 약관에 동의하지 않아 서비스를 이용하지 않는 회원의 탈퇴는 UC-21에서 다룬다.
- 위치 확인과 군민증 생성은 UC-04의 범위다.
- 서비스 이용약관·위치기반서비스 이용약관·개인정보 처리방침은 변경하지 않고 새 버전 행을 추가한다. 과거 문서와 동의 이력은 보존한다.
- 출시 시점에는 마케팅 정보 수신 동의를 제공하지 않는다.
