# 가입

## 목적

UC-01에서 등록된 신규 회원이 필수 약관 동의와 군민증 발급까지 온보딩을 완료한다.

이 유즈케이스는 별도 회원 생성 API를 추가하지 않고 UC-01, UC-03, UC-04를 연결해 전체 사용자 흐름을 통합 검증한다.

## 사전 조건

- 가입되지 않은 소셜 계정으로 인증한 상태다.

## 기본 흐름

1. UC-01 로그인에서 신규 회원, 소셜 계정과 기본 서비스 설정을 만들고 인증 세션을 발급한다.
2. 사용자가 필수 약관에 동의한다.
3. 시스템이 사용자의 현재 위치가 서버에 고정된 부여 행정구역 경계 안인지 확인한다.
4. 부여 안에 있으면 사용자가 디지털 군민증을 만든다.
5. 부여 밖이거나 위치를 확인할 수 없으면 위치 확인 안내를 표시하고 군민증 생성을 허용하지 않는다.
6. 군민증 발급을 완료한 사용자는 여행을 시작할 수 있다.

## 예외 흐름

- 필수 약관에 동의하지 않으면 위치 확인과 군민증 생성으로 진행하지 않는다.
- 회원 생성에 실패하면 가입을 완료하지 않고 다시 시도할 수 있게 한다.
- 네트워크 연결에 실패하면 네트워크 오류를 안내한다.

## 범위 경계

- 회원 생성과 인증 세션 발급의 구현·인수 조건은 UC-01이 소유한다.
- 약관 동의의 구현·인수 조건은 UC-03이 소유한다.
- 위치 확인과 군민증 발급의 구현·인수 조건은 UC-04가 소유한다.
- 이 유즈케이스는 세 유즈케이스가 완료된 뒤 신규 회원의 전체 온보딩 흐름을 통합 인수 검증한다.
