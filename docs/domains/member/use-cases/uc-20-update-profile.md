# 프로필 정보 수정

## 목적

사용자가 군민증과 마이페이지에 표시되는 프로필 정보를 변경한다.

## 사전 조건

- 사용자가 로그인 상태다.
- 사용자가 디지털 군민증을 발급받았다.

## 기본 흐름

1. 사용자가 마이페이지에서 프로필 수정 버튼을 누른다.
2. 사용자가 표시 이름, 프로필 캐릭터 또는 카드 테마를 변경한다.
3. 사용자가 `저장하기`를 누르면 앱이 변경한 필드만 제출한다.
4. 시스템이 생략한 필드를 유지하고 변경된 전체 회원 정보를 반환한다.
5. 앱이 변경된 프로필을 표시하고 완료 메시지를 보여준다.

## 예외 흐름

- 표시 이름은 앞뒤 공백을 제거한 뒤 Unicode 문자 기준 1~8자여야 하며 제어문자를 포함할 수 없다.
- 존재하지 않는 캐릭터·카드 테마, `null`, 잘못된 타입, 알 수 없는 필드 또는 변경 필드가 없는 요청은 `400 INVALID_REQUEST`이며 기존 프로필과 군민증을 유지한다.
- 군민증을 발급받지 않은 회원은 `409 INVALID_STATE_TRANSITION`이며 프로필을 만들거나 변경하지 않는다.
- 저장에 실패하면 기존 프로필을 유지하고 오류를 안내한다.

## 동시 요청

- 프로필 수정은 활성 회원 행을 먼저 잠그고 현재 프로필을 기준으로 생략 필드를 유지한다.
- 표시 이름, 캐릭터와 카드 테마를 각각 바꾸는 동시 요청은 직렬화해 모든 변경을 보존한다.
- 같은 필드를 동시에 바꾸면 가장 나중에 확정된 값을 사용한다.
- 회원 탈퇴와 경합하면 탈퇴를 우선하고 탈퇴 확정 이후 프로필 변경을 거부한다.

## 범위 경계

- 표시 이름, 캐릭터와 카드 테마만 변경할 수 있으며 군민증 발급일과 바코드는 변경하지 않는다.
- 현재 값과 같은 요청은 `200`과 현재 회원 정보를 반환하고 `updated_at`을 포함한 DB 상태를 변경하지 않는다.
- 프로필 수정은 군민증 발급 상태를 변경하지 않는다.
