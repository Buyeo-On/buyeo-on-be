# 근처 퀴즈 알림 동의

## 목적

사용자가 현재 기기의 푸시 토큰을 인증 세션에 연결하고 근처 퀴즈와 한정 미션 알림을 받을지 선택한다.

## 사전 조건

- 사용자가 로그인 상태다.
- 사용자가 알림 화면에 진입한 상태다.
- 사용자가 근처 퀴즈 알림에 동의하지 않은 상태다.

## 기본 흐름

1. 사용자가 알림 조회 화면을 연다.
2. 사용자가 `알림 받기`를 선택한다.
3. 필요한 경우 기기의 알림과 위치 권한을 허용한다.
4. 앱이 현재 기기의 FCM 등록 토큰을 현재 인증 세션에 등록한다.
5. 토큰 등록이 성공하면 앱이 조회한 설정 버전과 기기의 알림·위치 권한 허용 값을 제출해 근처 퀴즈 알림을 켠다.
6. 앱이 변경된 설정을 반영하고 완료 메시지를 표시한다.

## 푸시 토큰 갱신·삭제

- FCM이 현재 기기에 새 등록 토큰을 발급하면 앱은 같은 API로 현재 인증 세션의 토큰을 교체한다.
- 같은 등록 토큰이 다른 활성 인증 세션에 연결돼 있으면 가장 나중에 확정된 현재 세션으로 연결을 옮긴다.
- 앱에서 더 이상 현재 토큰을 사용하지 않으면 현재 인증 세션의 푸시 토큰을 삭제할 수 있다.
- 등록되지 않은 현재 세션의 토큰 삭제는 성공으로 처리한다.
- 푸시 토큰 등록·갱신·삭제는 근처 퀴즈 알림 설정을 변경하지 않는다.

## 예외 흐름

- 사용자가 `다음에 할게요`를 선택하면 기존 설정을 유지한다.
- 기기 권한을 허용하지 않으면 알림을 켤 수 없음을 안내한다.
- 푸시 토큰 등록에 실패하면 설정 변경을 요청하지 않고 오류를 안내한다.
- 토큰 등록 후 설정 변경에 실패하면 근처 퀴즈 알림 설정은 기존 값을 유지한다. 등록된 토큰만으로는 근처 퀴즈 알림 발송 대상이 되지 않는다.
- 인증하지 않았거나 현재 인증 세션이 만료·폐기됐으면 토큰과 설정을 변경하지 않는다.

## 범위 경계

- `PATCH /members/me/settings`의 버전·권한·부분 변경 규칙은 UC-19가 소유하며 UC-11은 해당 API를 연결해 사용한다.
- 기기 권한과 FCM 등록 토큰 발급은 Flutter와 Firebase SDK가 담당한다.
- 실제 근처 퀴즈 판정, FCM 발송과 무효 토큰 정리는 알림 기능의 범위다.
- 이 UC에서 켜는 동의 필드는 근처 퀴즈 알림에서 유래했지만, MVP에서는 push를 발송하는 다른 알림 유형(부여 진입 등)의 동의 여부도 함께 결정한다. 자세한 내용은 [알림 도메인 규칙](../../notification/rules.md)을 참고한다.
