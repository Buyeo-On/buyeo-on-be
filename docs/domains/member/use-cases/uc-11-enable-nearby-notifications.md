# 근처 퀴즈 알림 동의

## 목적

사용자가 근처 퀴즈와 한정 미션 알림을 받을지 선택한다.

## 사전 조건

- 사용자가 로그인 상태다.
- 사용자가 알림 화면에 진입한 상태다.
- 사용자가 근처 퀴즈 알림에 동의하지 않은 상태다.

## 기본 흐름

1. 사용자가 알림 조회 화면을 연다.
2. 사용자가 `알림 받기`를 선택한다.
3. 필요한 경우 기기의 알림과 위치 권한을 허용한다.
4. 앱이 현재 기기의 FCM 등록 토큰을 현재 인증 세션에 등록한다.
5. 앱이 알림을 켜고 완료 메시지를 표시한다.

## 예외 흐름

- 사용자가 `다음에 할게요`를 선택하면 기존 설정을 유지한다.
- 기기 권한을 허용하지 않으면 알림을 켤 수 없음을 안내한다.
- 푸시 토큰 등록이나 설정 변경에 실패하면 기존 설정을 유지하고 오류를 안내한다.
