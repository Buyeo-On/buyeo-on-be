# 회원 도메인 모델과 규칙

## 책임

회원 가입과 인증, 약관 동의, 디지털 군민증, 프로필, 서비스 설정과 인증 세션에 연결된 푸시 토큰을 소유한다.

## 모델

### 회원

부여ON을 이용하는 사람이다. 가입 상태, 프로필, 약관 동의, 군민증과 여행 기록의 소유자다.

### 소셜 계정

회원 가입과 로그인에 사용하는 카카오 또는 Apple 외부 계정이다. 한 회원은 여러 제공자의 계정을 연결할 수 있다.

### 인증 세션

회원이 현재 로그인한 상태를 나타낸다. 로그아웃하거나 탈퇴하면 폐기된다.

### 약관과 약관 동의

약관은 서비스 이용약관, 개인정보 처리방침, 마케팅 정보 수신 동의처럼 회원에게 제시하는 정책이다. 약관 동의는 회원이 특정 약관의 특정 버전에 동의했는지를 나타낸다.

### 디지털 군민증과 프로필

디지털 군민증은 회원이 부여에서 발급받는 임시 시민 자격이다. 표시 이름, 캐릭터, 카드 테마, 발급일과 바코드를 포함한다. 프로필은 마이페이지와 군민증에 표시되는 이름과 캐릭터다.

### 바코드

군민증과 보유 포인트를 제시하는 수단이다. MVP에서는 실제 상점 결제가 아닌 시연 용도로 사용한다.

### 푸시 토큰

현재 인증 세션의 기기로 FCM 알림을 보내기 위한 등록 토큰이다. 액세스 JWT의 `sid`로 인증 세션을 식별하며 세션마다 하나만 활성 상태로 관리한다.

### 서비스 설정

GPS 유적지 인근 알림과 다크 모드처럼 회원이 변경할 수 있는 이용 환경이다. 회원 도메인이 설정 값을 저장하고 알림 도메인은 알림 발송 자격을 판단할 때 이를 사용한다.

## 규칙

1. 가입과 로그인은 카카오 또는 Apple 소셜 계정을 통해 진행한다.
2. 이미 가입된 소셜 계정은 새 회원을 만들지 않고 기존 회원으로 로그인한다.
3. 신규 회원 가입은 회원, 소셜 계정과 기본 서비스 설정을 하나의 트랜잭션으로 생성한다.
4. 같은 소셜 계정의 가입 요청이 동시에 처리돼도 회원은 하나만 생성하며, 경합에서 뒤진 요청은 생성된 기존 회원의 로그인으로 처리한다.
5. 로그인할 때마다 새 인증 세션을 만들며 한 회원의 여러 기기 세션을 허용한다.
6. 탈퇴한 회원의 소셜 계정은 새 회원으로 재가입시키거나 기존 회원을 활성 상태로 되돌리지 않는다.
7. 약관 종류별 현재 버전은 `effective_at`이 현재 시각 이하인 버전 중 가장 최근 버전이며 미래 시행 버전은 현재 약관으로 노출하지 않는다.
8. 같은 약관 종류에 동일한 `effective_at`을 가진 두 버전을 만들 수 없다.
9. 신규 회원은 현재 필수 약관 전체에 동의해야 다음 단계로 진행할 수 있다.
10. 서비스 이용약관과 개인정보 처리방침은 필수 약관이다.
11. 마케팅 정보 수신 동의는 선택 약관이며 동의하지 않아도 서비스를 이용할 수 있다.
12. 약관 동의 저장은 현재 약관 전체에 대한 결정을 한 번에 받는다. 필수 약관은 동의만 허용하고 선택 약관은 동의와 거부를 모두 허용한다.
13. 제출한 약관 ID와 버전은 현재 약관과 정확히 일치해야 하며 누락·중복·과거·미래 버전이 있으면 어떤 동의도 변경하지 않는다.
14. 한 번의 요청으로 저장한 약관 동의는 같은 확정 시각을 사용하고, 과거 약관 버전의 동의 이력은 유지한다.
15. 새 필수 약관 버전이 시행되면 기존 동의를 완료한 회원도 새 버전에 동의할 때까지 필수 약관 미동의 상태다.
16. 현재 필수 약관 동의가 끝나면 군민증 안내로 진행한다.
17. 군민증은 로그인하고 필수 약관에 동의한 회원이 부여 지역 안에 있을 때만 만들 수 있다.
18. 회원은 군민증을 한 번만 발급받으며 이미 발급한 회원의 새 생성 요청은 기존 군민증을 변경하지 않는다.
19. 군민증을 만들 때 표시 이름, 승인된 프로필 캐릭터와 승인된 카드 테마를 모두 선택해야 한다.
20. 표시 이름은 앞뒤 공백을 제거한 Unicode 문자 기준 1~8자여야 하며 공백만 있거나 제어문자를 포함할 수 없다.
21. 군민증 생성은 회원 프로필, 군민증과 성공 멱등성 기록을 하나의 트랜잭션으로 확정한다.
22. 군민증의 바코드 값은 서버가 생성한 UUID 문자열이며 MVP 시뮬레이션 식별자로만 사용한다.
23. 프로필 수정으로 표시 이름과 캐릭터를 변경할 수 있다.
24. 군민증이 없는 회원은 군민증과 바코드를 볼 수 없다.
25. 바코드는 실제 결제, 포인트 차감이나 가맹점 인증에 사용할 수 없다.
26. 군민증 조회는 현재 프로필의 표시 이름·캐릭터와 발급 시 선택한 카드 테마를 사용한다.
27. 캐릭터와 카드 테마 목록은 각 카탈로그의 `sort_order` 오름차순으로 반환한다.
28. 로그아웃은 인증 세션만 종료하며 회원 정보와 여행 기록은 유지한다.
29. 탈퇴가 완료되면 로그인할 수 없으며 관련 정보는 삭제 정책에 따라 처리한다.
30. 같은 FCM 등록 토큰이 새 인증 세션에 등록되면 기존 세션에서 새 세션으로 소유권을 옮긴다.
31. 로그아웃하거나 탈퇴하면 해당 인증 세션의 푸시 토큰을 더 이상 발송 대상으로 사용하지 않는다.
32. 근처 퀴즈 알림과 다크 모드 설정은 서로 독립적으로 변경할 수 있다.
33. 서비스 설정 변경에 실패하면 기존 설정을 유지한다.

## 상태 전이

| 모델 | 허용 상태 전이 | 규칙 |
| --- | --- | --- |
| 회원 | 가입 전 → 활성 → 탈퇴 | 탈퇴한 회원은 활성 상태로 되돌리지 않는다. |
| 디지털 군민증 | 미발급 → 발급 | 프로필 수정은 발급 상태를 바꾸지 않는다. |
| 푸시 토큰 | 미등록 ↔ 등록 | 현재 인증 세션에서 등록·갱신·삭제할 수 있다. |
| 근처 퀴즈 알림 설정 | 미동의 ↔ 동의 | 회원이 서비스 설정에서 변경할 수 있다. |
