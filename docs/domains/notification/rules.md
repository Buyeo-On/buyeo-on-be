# 알림 도메인 모델과 규칙

## 책임

회원에게 표시하는 알림과 FCM 발송을 소유한다. 근처 퀴즈 알림 설정, 인증 세션과 푸시 토큰의 연결 상태는 회원 도메인이 소유한다.

## 모델

### 알림

포인트 적립, 배지 획득, 주변 퀴즈, 지역화폐 할인, 군민증 발급과 부여 소식을 회원에게 전달한다.

### 알림 발송 자격

회원 도메인의 근처 퀴즈 알림 설정, 기기 권한, 활성 인증 세션과 푸시 토큰을 조합해 현재 회원에게 푸시를 발송할 수 있는지를 나타낸다.

## 규칙

1. 알림은 최근 알림과 지난 알림으로 나누어 조회할 수 있다.
2. 근처 퀴즈 알림은 회원 도메인의 설정이 동의 상태인 경우에만 제공한다.
3. 근처 퀴즈 알림을 제공하려면 기기의 알림 권한과 위치 권한이 필요하다.
4. 회원이 `다음에 할게요`를 선택하면 기존 알림 설정을 유지한다.
5. 기기 권한이 없으면 알림을 켤 수 없음을 안내한다.
6. 앱은 알림 권한을 얻고 로그인한 뒤 현재 인증 세션의 푸시 토큰을 서버에 등록한다.
7. 서버는 폐기됐거나 만료된 인증 세션의 푸시 토큰으로 알림을 보내지 않는다.
8. FCM이 토큰 만료 또는 무효를 응답하면 서버는 해당 토큰을 삭제한다.
