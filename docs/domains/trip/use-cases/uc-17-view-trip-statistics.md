# 여행 통계 조회

## 목적

사용자가 부여에서의 여행 활동을 요약해 확인한다.

## 사전 조건

- 사용자가 로그인 상태다.
- 여행 기록이 존재한다.

## 기본 흐름

1. 사용자가 `활동내역` 탭을 누른다.
2. 사용자가 오늘의 탐험 요약으로 이동한다.
3. 앱이 탐방한 문화재 수, 탐방 시간, 이 여행에서 적립한 포인트를 표시한다. 탐방 시간은 종료된 여행은 시작부터 종료까지, 진행 중인 여행은 시작부터 현재까지 계산한다. 적립 포인트는 해당 여행의 `EARN` 내역 합계이며 없으면 `0`이다.
4. 이동 거리와 소모 칼로리는 MVP에서 계산하지 않고 `null` 상태로 표시한다.

## 예외 흐름

- 여행 기록이 없으면 통계가 없는 상태를 표시한다.
- 조회에 실패하면 네트워크 오류를 안내한다.
