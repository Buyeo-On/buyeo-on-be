# 여행 사진 조회

## 목적

사용자가 진행 중이거나 종료한 여행에서 그때까지 촬영한 사진을 확인한다.

## 사전 조건

- 사용자가 로그인 상태다.
- 여행 기록이 존재한다.

## 기본 흐름

1. 사용자가 `활동내역` 탭을 누른다.
2. 앱이 오늘의 추억 사진으로 해당 여행에서 업로드 시각 순으로 촬영한 사진을, 사진을 찍은 미션이 연결된 장소명과 함께 표시한다.
3. 사용자가 사진을 눌러 크게 본다.

## 예외 흐름

- 촬영한 사진이 없으면 빈 목록을 표시한다.
- 다른 회원의 여행이거나 존재하지 않는 여행이면 조회에 실패했음을 안내한다.
- 조회에 실패하면 네트워크 오류를 안내한다.

## 발자취 조회와의 차이

[UC-25 발자취 조회](./uc-25-view-footprint.md)는 여행이 종료되고 포인트 정산을 마친(`SETTLED`) 뒤에만 조회할 수 있는 회고 기록이다. 이 유스케이스는 여행 상태와 무관하게 사진만 가볍게 조회하며, 진행 중인 여행에서도 사용할 수 있다.
