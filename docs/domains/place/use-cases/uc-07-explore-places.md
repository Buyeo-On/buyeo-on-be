# 가볼 곳 탐색

## 목적

사용자는 문화재 또는 장소를 탐색한다.

## 사전 조건

- 사용자가 로그인 상태다.
- 사용자가 필수 약관에 동의한 상태다.
- 진행 중인 여행 세션이 존재한다.

## 기본 흐름

1. 사용자의 위치 근방에 있는 문화재와 장소를 조회한다.
2. 장소나 문화재 한 곳의 사진, 이름, 카테고리, 도보 거리를 조회한다. TourAPI 대표이미지가 표시되면 제공기관·서비스·이용허락 유형·원문 링크를 함께 조회한다.
3. 관리자 이미지와 TourAPI 대표이미지가 모두 없으면 클라이언트가 플레이스홀더를 표시할 수 있도록 이미지 없이 반환한다.

## 예외 흐름

- 네트워크 연결에 실패하면 네트워크 오류를 안내한다.
