# 포인트 도메인 모델과 규칙

## 책임

회원의 포인트 잔액과 내역, 미션 완료 보상과 여행 종료 후 포인트 정산을 소유한다.

## 모델

### 포인트 잔액

회원이 현재 보유한 부여 포인트다.

### 포인트 내역

포인트가 언제, 어떤 활동으로 얼마나 변했는지를 나타내는 기록이다.

### 포인트 정산

여행 종료 후 해당 여행에서 적립하고 아직 정산하지 않은 포인트를 부여에 남기거나 다음 방문까지 유지하는 선택이다.

## 정합성 규칙

1. 포인트 잔액이 변하면 반드시 같은 금액의 포인트 내역이 남아야 한다.
2. 포인트 잔액은 유효한 포인트 내역의 합계와 항상 일치해야 한다.
3. 포인트 잔액은 0보다 작아질 수 없다.
4. 하나의 미션 완료에는 포인트 보상을 한 번만 지급한다.
5. 미션 완료, 포인트 내역 생성과 포인트 잔액 변경은 하나의 처리 단위로 본다.
6. 여행 포인트 정산은 해당 여행에서 적립하고 아직 정산하지 않은 포인트만 대상으로 하며, `부여에 남기기`와 `다음에 이어서 쓰기` 중 하나로만 정산할 수 있다.
7. 다른 여행에서 이월한 포인트는 현재 여행의 정산 대상에 포함하지 않는다.
8. `부여에 포인트 남기고 가기`를 선택하면 정산 대상 포인트는 더 이상 사용할 수 없고 골목상권 기여로 처리한다.
9. `다음에 이어서 쓰기`를 선택하면 정산 완료 시각부터 `10×24시간` 동안 유지한다.
10. 남은 포인트가 없으면 정산을 건너뛴다.
11. 정산에 실패하면 잔액과 내역을 정산 전 상태로 유지한다.
12. MVP의 군민증 바코드 조회는 조회 시점의 포인트 내역 `amount` 합계를 반환하고 내역이 없으면 `0`을 반환한다.
13. 군민증 바코드 조회는 포인트 잔액을 차감하거나 포인트 내역을 만들지 않는다.

## 상태 전이

| 모델 | 허용 상태 전이 | 규칙 |
| --- | --- | --- |
| 포인트 정산 | 정산 대기 → 부여에 남김 또는 유지 | 한 번 확정한 정산 결과는 다른 결과로 다시 확정하지 않는다. |
