# ADR-004: 상태 컬럼은 명확한 생명주기가 있을 때만 둔다

- **상태:** 승인됨
- **결정일:** 2026-08-09
## 맥락
캐릭터, 카드 테마, 장소, 미션, 배지에 범용 `active` 컬럼이 있었지만 비활성화 동작과 운영 유스케이스가 정의되지 않았다. 반면 회원 탈퇴와 배지 지급 중단은 유지해야 할 이력이 있는 명확한 상태 변화다.
## 결정
- 명확한 비활성화 요구가 없는 카탈로그에는 범용 `active` 컬럼을 두지 않는다.
- 회원의 `ACTIVE`·`WITHDRAWN` 상태는 로그인 차단과 개인정보 파기 규칙을 위해 유지한다.
- 배지 삭제는 획득 이력을 보존해야 하므로 물리 삭제 대신 `retired_at`으로 신규 지급만 중단한다.
- 지급 중단 전 획득한 배지는 유지하며 회수하지 않는다.
## 결과
- 의미가 정의되지 않은 상태 분기와 필터 조건이 줄어든다.
- 새로운 생명주기가 필요해지면 구체적인 전이와 기존 참조 처리 규칙을 먼저 정의해야 한다.
## 기각한 대안
- 모든 카탈로그에 관례적으로 `active boolean`을 두는 방식
- 지급된 배지 정의를 물리 삭제해 회원 획득 이력을 함께 잃는 방식
