# ADR-001: 소셜 계정은 로그인된 회원이 명시적으로 연결한다

- **상태:** 승인됨
- **결정일:** 2026-08-09
## 맥락
한 회원이 카카오와 Apple 계정을 함께 사용할 수 있어야 한다. 이메일은 제공되지 않거나 Apple 릴레이 주소일 수 있으며, 이메일 일치만으로 계정을 병합하면 잘못된 연결 위험이 있다.
## 결정
- 회원과 소셜 계정은 `members`와 `social_accounts`의 1:N 관계로 관리한다.
- 다른 제공자 계정은 로그인된 회원이 `POST /members/me/social-accounts`로 연결한다.
- 서비스 액세스 토큰은 기존 회원을 증명한다. 새 소셜 계정은 카카오 네이티브 SDK access token 또는 Apple 인가 코드·identity token·nonce를 서버가 제공자 기준으로 검증해 증명한다.
- 검증된 제공자 subject만 소셜 계정 식별자로 저장하고 이메일 일치 여부는 사용하지 않는다.
- 별도 이메일 인증과 이메일만을 이용한 자동 병합은 사용하지 않는다.
- 다른 회원에게 연결된 계정이나 같은 제공자의 다른 계정과 충돌하면 `409`를 반환한다.
## 결과
- 이메일 제공 여부와 무관하게 안전하게 여러 제공자를 연결할 수 있다.
- 사용자가 원래 계정으로 로그인할 수 없는 상태에서는 다른 제공자를 자동 연결하지 않는다.
## 기각한 대안
- 이메일 일치만으로 계정을 자동 병합하는 방식
- 공개 로그인 API가 액세스 토큰 유무에 따라 로그인과 연결을 함께 처리하는 방식
