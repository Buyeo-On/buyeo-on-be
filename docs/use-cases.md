# 유즈케이스

## 로그인
### 목적
기존 회원이 소셜 계정으로 인증하고 현재 온보딩 상태에 맞는 화면으로 이동한다.
### 사전 조건
- 사용자가 로그인 화면에 진입한 상태다.
- 사용자가 인터넷에 연결되어 있다.
### 기본 흐름
1. 사용자가 `카카오로 시작하기` 또는 `Apple로 시작하기` 버튼을 누른다.
2. 시스템이 선택한 소셜 로그인 화면을 제공한다.
3. 사용자가 카카오 또는 Apple(애플) 계정으로 로그인하고 필요한 정보 제공에 동의한다.
4. 시스템이 기존 회원 여부와 온보딩 상태를 확인한다.
5. 기존 회원이면 로그인을 완료하고 다음 기준으로 이동한다.
	1. 필수 약관 미동의: 약관 동의 화면
	2. 필수 약관 동의 완료, 군민증 미발급: 위치 확인 및 군민증 안내 화면
	3. 군민증 발급 완료: 진행 중 여행 또는 탐방 시작 화면
### 예외 흐름
- 가입되지 않은 소셜 계정이면 신규 회원을 만들고 가입 흐름으로 진행한다.
- 네트워크 연결에 실패하면 네트워크 오류를 안내한다.
- 사용자가 정보 제공에 동의하지 않으면 로그인을 중단한다.
## 가입
### 목적
신규 사용자를 등록하고 필수 온보딩을 진행한다.
### 사전 조건
- 가입되지 않은 소셜 계정으로 인증한 상태다.
### 기본 흐름
1. 시스템이 소셜 계정의 기본 정보로 신규 회원을 만든다.
2. 사용자가 필수 약관에 동의한다.
3. 시스템이 사용자의 현재 위치가 부여 행정구역 안인지 확인한다.
4. 부여 안에 있으면 사용자가 디지털 군민증을 만든다.
5. 부여 밖이거나 위치를 확인할 수 없으면 위치 확인 안내를 표시하고 군민증 생성을 허용하지 않는다.
6. 군민증 발급을 완료한 사용자는 여행을 시작할 수 있다.
### 예외 흐름
- 필수 약관에 동의하지 않으면 위치 확인과 군민증 생성으로 진행하지 않는다.
- 회원 생성에 실패하면 가입을 완료하지 않고 다시 시도할 수 있게 한다.
- 네트워크 연결에 실패하면 네트워크 오류를 안내한다.
## 약관 동의
### 목적
사용자는 필수 및 선택 약관에 동의한다.
### 사전 조건
- 사용자는 필수 약관 중 동의하지 않은 항목이 있다.
### 기본 흐름
1. 사용자는 약관 항목과 세부사항을 읽는다.
2. 사용자는 원하는 항목에 동의한다.
3. 필수 항목에 모두 동의하면 `동의하고 계속하기`를 누른다.
4. 앱이 약관 동의를 저장한다.
5. 동의가 끝나면 현재 위치를 확인하고 디지털 군민증 안내 화면으로 이동한다.
### 예외 흐름
- 필수 항목에 동의하지 않으면 계속하기 버튼을 활성화하지 않는다.
- 처리에 실패하면 네트워크 오류를 안내한다.
## 군민증 생성
### 목적
사용자가 디지털 군민증을 생성한다.
### 사전 조건
- 사용자가 로그인 상태다.
- 사용자가 필수 약관에 동의한 상태다.
- 사용자의 위치가 부여에 있다.
### 기본 흐름
1. 사용자는 군민증에 표시될 이름을 지정한다.
2. 사용자는 군민증의 프로필 캐릭터를 지정한다.
3. 사용자는 군민증의 카드 테마를 지정한다.
4. 위 세 가지 항목이 지정된 경우
	1. 사용자는 군민증을 만든다.
5. 지정하지 않은 경우
	1. 지정하지 않은 부분의 UI에 표시한다.
### 예외 흐름
- 네트워크 연결에 실패하면 네트워크 오류를 안내한다.
## 여행 시작
### 목적
사용자가 여행 세션을 시작한다.
### 사전 조건
- 사용자가 로그인 상태다.
- 사용자가 필수 약관에 동의한 상태다.
- 사용자가 디지털 군민증을 발급받았다.
- 사용자의 위치가 부여에 있다.
### 기본 흐름
1. 사용자는 여행을 시작한다.
### 예외 흐름
- 네트워크 연결에 실패하면 네트워크 오류를 안내한다.
## 퀴즈 탐색
### 목적
사용자는 근처에 있는 퀴즈를 조회한다.
### 사전 조건
- 사용자가 로그인 상태다.
- 사용자가 필수 약관에 동의한 상태다.
- 여행 중인 여행 세션이 존재한다.
### 기본 흐름
1. 사용자의 위치 근방에 있는 퀴즈를 조회한다.
2. 퀴즈와 사용자의 거리가 100m 이하인 경우
	1. 마커가 활성화된다.
3. 퀴즈와 사용자의 거리가 100m 초과인 경우
	1. 마커가 회색으로 비활성화된다.
### 예외 흐름
네트워크 연결에 실패하면 네트워크 오류를 안내한다.
## 가볼곳 탐색
### 목적
사용자는 문화재 혹은 장소를 탐색한다.
### 사전 조건
- 사용자가 로그인 상태다.
- 사용자가 필수 약관에 동의한 상태다.
- 여행 중인 여행 세션이 존재한다.
### 기본 흐름
1. 사용자의 위치 근방에 있는 문화재와 장소를 조회한다.
2. 장소나 문화재 한 곳의 사진, 이름, 카테고리, 도보 거리를 조회한다.
### 예외 흐름
네트워크 연결에 실패하면 네트워크 오류를 안내한다.
## 가볼곳 저장
### 목적
사용자가 조회한 장소 또는 문화재를 저장한다.
### 사전 조건
- 사용자가 로그인 상태다.
- 사용자가 장소 상세 정보를 조회한 상태다.
### 기본 흐름
1. 사용자가 장소 또는 문화재의 상세 정보를 확인한다.
2. 사용자가 `저장하기`를 누른다.
3. 앱이 장소를 저장하고 완료 상태를 표시한다.
### 예외 흐름
- 이미 저장한 장소면 저장된 상태를 유지한다.
- 저장에 실패하면 네트워크 오류를 안내한다.
## 퀴즈 풀이
### 목적
사용자는 현장에서 퀴즈 또는 사진 인증 미션에 참여한다.
### 사전 조건
- 사용자가 로그인 상태다.
- 여행 중인 여행 세션이 존재한다.
- 퀴즈와 사용자의 거리가 100m 이내다.
### 기본 흐름
1. 스페셜 퀴즈인 경우 사용자가 도전 기회를 확인하고 도전한다.
2. 객관식 또는 OX 퀴즈인 경우 사용자가 문제를 읽고 답을 선택한다.
3. 앱이 제출한 답의 정답 여부를 표시한다.
4. 사진 인증 미션인 경우 사용자가 안내에 따라 사진을 촬영한다.
5. 사용자가 촬영 결과를 확인하고 제출하면 앱이 인증 완료로 처리한다.
6. 미션을 처음 완료하면 앱이 미션과 연결된 문화재의 방문 기록을 현재 여행에 생성한다.
7. 같은 여행에 해당 문화재의 방문 기록이 이미 있으면 중복 생성하지 않는다.
### 예외 흐름
- 퀴즈의 위치 조건을 충족하지 않으면 잠금 상태를 표시한다.
- 카메라 권한이 없으면 권한 허용을 안내한다.
- 스페셜 퀴즈의 도전 기회가 없으면 참여할 수 없음을 안내한다.
## 알림 조회
### 목적
사용자가 부여 여행 중 발생한 알림을 확인한다.
### 사전 조건
- 사용자가 로그인 상태다.
### 기본 흐름
1. 사용자가 탐험 화면에서 알림 버튼을 누른다.
2. 앱이 최근 알림과 지난 알림을 표시한다.
3. 사용자가 알림의 종류, 내용, 발생 시각을 확인한다.
### 예외 흐름
- 알림이 없으면 알림이 없는 상태를 표시한다.
- 조회에 실패하면 네트워크 오류를 안내한다.
## 근처 퀴즈 알림 동의
### 목적
사용자가 근처 퀴즈와 한정 미션 알림을 받을지 선택한다.
### 사전 조건
- 사용자가 로그인 상태다.
- 사용자가 알림 화면에 진입한 상태다.
- 사용자가 근처 퀴즈 알림 동의를 하지 않은 상태이다.
### 기본 흐름
1. 사용자가 알림 조회 화면을 연다.
2. 사용자가 `알림 받기`를 선택한다.
3. 필요한 경우 기기의 알림과 위치 권한을 허용한다.
4. 앱이 알림을 켜고 완료 메시지를 표시한다.
### 예외 흐름
- 사용자가 `다음에 할게요`를 선택하면 기존 설정을 유지한다.
- 기기 권한을 허용하지 않으면 알림을 켤 수 없음을 안내한다.
## 저장한 장소 조회
### 목적
사용자가 저장한 유적지, 식당, 카페를 다시 확인한다.
### 사전 조건
- 사용자가 로그인 상태다.
### 기본 흐름
1. 사용자가 하단의 `저장` 탭을 누른다.
2. 앱이 저장한 장소 목록과 개수를 표시한다.
3. 사용자가 전체, 유적지, 식당, 카페 중 원하는 분류를 선택한다.
4. 사용자가 장소를 선택해 상세 정보와 현재 위치에서의 거리를 확인한다.
### 예외 흐름
- 저장한 장소가 없으면 빈 저장 목록을 표시한다.
- 조회에 실패하면 네트워크 오류를 안내한다.
## 저장한 장소 삭제
### 목적
사용자가 더 이상 필요하지 않은 장소를 저장 목록에서 삭제한다.
### 사전 조건
- 사용자가 로그인 상태다.
- 해당 장소가 저장 목록에 있다.
### 기본 흐름
1. 사용자가 저장한 장소의 상세 정보를 연다.
2. 사용자가 `저장 목록에서 삭제`를 누른다.
3. 앱이 장소를 목록에서 제거하고 완료 메시지를 표시한다.
### 예외 흐름
- 이미 삭제된 장소면 최신 저장 목록을 표시한다.
- 삭제에 실패하면 네트워크 오류를 안내한다.
## 배지 획득
### 목적
사용자가 탐험 활동으로 배지를 획득한다.
### 사전 조건
- 사용자가 로그인 상태다.
- 사용자가 배지의 달성 조건을 충족했다.
### 기본 흐름
1. 사용자가 배지 조건을 달성한다.
2. 앱이 새로 획득한 배지를 확인한다.
3. 앱이 배지 아이콘, 이름, 달성 조건을 표시한다.
### 예외 흐름
- 이미 획득한 배지면 중복으로 지급하지 않는다.
## 군민증 바코드 보기
### 목적
사용자가 MVP에서 디지털 군민증과 포인트 바코드를 확인한다.
### 사전 조건
- 사용자가 로그인 상태다.
- 사용자가 디지털 군민증을 발급받았다.
### 기본 흐름
1. 사용자가 탐험 화면 또는 활동 내역에서 `군민증 바코드`를 누른다.
2. 앱이 디지털 군민증, 바코드, 보유 포인트를 표시한다.
3. 사용자가 바코드를 확인하거나 MVP 시연에 사용한다.
4. 앱이 실제 상점에서의 사용은 제한된다는 안내를 표시한다.
5. 사용자가 바코드 화면을 닫는다.
### 예외 흐름
- 군민증이 없으면 군민증 생성을 안내한다.
- 바코드를 불러오지 못하면 다시 시도하도록 안내한다.
## 포인트 적립 내역 조회
### 목적
사용자가 포인트를 언제, 어떤 활동으로 적립했는지 확인한다.
### 사전 조건
- 사용자가 로그인 상태다.
### 기본 흐름
1. 사용자가 `활동내역` 탭을 누른다.
2. 앱이 누적 포인트와 포인트 적립 내역을 표시한다.
3. 사용자가 활동명, 적립 시각, 적립 포인트를 확인한다.
### 예외 흐름
- 적립 내역이 없으면 내역이 없는 상태를 표시한다.
- 조회에 실패하면 네트워크 오류를 안내한다.
## 여행 통계 조회
### 목적
사용자가 부여에서의 여행 활동을 요약해 확인한다.
### 사전 조건
- 사용자가 로그인 상태다.
- 여행 기록이 존재한다.
### 기본 흐름
1. 사용자가 `활동내역` 탭을 누른다.
2. 사용자가 오늘의 탐험 요약으로 이동한다.
3. 앱이 탐방한 문화재 수와 탐방 시간을 표시한다. 탐방 시간은 종료된 여행은 시작부터 종료까지, 진행 중인 여행은 시작부터 현재까지 계산한다.
4. 이동 거리와 소모 칼로리는 MVP에서 계산하지 않고 `null` 상태로 표시한다.
### 예외 흐름
- 여행 기록이 없으면 통계가 없는 상태를 표시한다.
- 조회에 실패하면 네트워크 오류를 안내한다.
## 배지 진척도 조회
### 목적
사용자가 부여 탐험 배지의 획득 여부와 달성 진행도를 확인한다.
### 사전 조건
- 사용자가 로그인 상태다.
### 기본 흐름
1. 사용자가 활동 내역에서 `부여 탐험 배지`의 전체보기를 누른다.
2. 앱이 분야별 배지와 전체 획득 현황을 표시한다.
3. 사용자가 각 배지의 달성 조건과 현재 진행도를 확인한다.
### 예외 흐름
- 획득한 배지가 없어도 전체 배지와 진행도를 표시한다.
- 조회에 실패하면 네트워크 오류를 안내한다.
## 서비스 설정
### 목적
사용자가 여행 중 필요한 알림과 화면 표시 방식을 설정한다.
### 사전 조건
- 사용자가 로그인 상태다.
### 기본 흐름
1. 사용자가 `마이페이지`에 진입한다.
2. 사용자가 GPS 유적지 인근 알림 또는 다크 모드 설정을 변경한다.
3. 앱이 변경한 설정을 적용하고 현재 상태를 표시한다.
### 예외 흐름
- 기기 권한이 꺼져 있으면 권한 설정이 필요함을 안내한다.
- 설정 변경에 실패하면 기존 설정을 유지하고 오류를 안내한다.
## 프로필 정보 수정
### 목적
사용자가 군민증과 마이페이지에 표시되는 프로필 정보를 변경한다.
### 사전 조건
- 사용자가 로그인 상태다.
- 사용자가 디지털 군민증을 발급받았다.
### 기본 흐름
1. 사용자가 마이페이지에서 프로필 수정 버튼을 누른다.
2. 사용자가 표시 이름과 프로필 캐릭터를 변경한다.
3. 사용자가 `저장하기`를 누른다.
4. 앱이 변경된 프로필을 표시하고 완료 메시지를 보여준다.
### 예외 흐름
- 이름이 8자를 초과하면 수정이 필요한 항목을 안내한다.
- 저장에 실패하면 기존 프로필을 유지하고 오류를 안내한다.
## 탈퇴
### 목적
사용자가 부여ON 회원 자격을 종료한다.
### 사전 조건
- 사용자가 로그인 상태다.
### 기본 흐름
1. 사용자가 마이페이지에서 `회원탈퇴`를 누른다.
2. 앱이 탈퇴 시 삭제되는 정보와 유의사항을 안내한다.
3. 사용자가 탈퇴를 확정한다.
4. 앱이 탈퇴를 완료하고 로그인 화면으로 이동한다.
### 예외 흐름
- 사용자가 취소하면 마이페이지로 돌아간다.
- 탈퇴에 실패하면 오류를 안내하고 로그인 상태를 유지한다.
## 로그아웃
### 목적
사용자가 현재 기기에서 로그인 상태를 종료한다.
### 사전 조건
- 사용자가 로그인 상태다.
### 기본 흐름
1. 사용자가 마이페이지에서 `로그아웃`을 누른다.
2. 앱이 로그아웃 여부를 다시 확인한다.
3. 사용자가 로그아웃을 확정한다.
4. 앱이 로그인 상태를 종료하고 로그인 화면으로 이동한다.
### 예외 흐름
- 사용자가 취소하면 마이페이지로 돌아간다.
## 여행 끝내기
### 목적
사용자가 진행 중인 부여 여행을 마친다.
### 사전 조건
- 사용자가 로그인 상태다.
- 진행 중인 여행 세션이 존재한다.
### 기본 흐름
1. 사용자가 마이페이지에서 `부여 떠나기`를 누르거나 부여 지역을 벗어난다.
2. 앱이 오늘의 방문 장소와 지역 상권 기여 내용을 보여준다.
3. 사용자가 여행 끝내기를 확인한다.
4. 앱이 여행을 종료하고 남은 포인트 정산으로 이동한다.
### 예외 흐름
- 사용자가 취소하면 여행을 계속한다.
- 진행 중인 여행이 없으면 종료할 여행이 없음을 안내한다.
## 여행 포인트 정산
### 목적
사용자가 여행에서 남은 포인트의 처리 방법을 선택한다.
### 사전 조건
- 사용자가 로그인 상태다.
- 여행 세션이 종료된 상태다.
### 기본 흐름
1. 앱이 이번 여행에서 적립하고 아직 정산하지 않은 포인트와 사용 가능 기간을 표시한다. 다른 여행에서 이월한 포인트는 정산 대상에서 제외한다.
2. 사용자가 `부여에 포인트 남기고 가기` 또는 `다음에 이어서 쓰기`를 선택한다.
3. 포인트를 남기면 앱이 골목상권 기여 결과를 표시한다.
4. 이어서 쓰기를 선택하면 앱이 포인트를 10일 동안 유지한다.
5. 앱이 정산 결과를 표시하고 발자취 조회로 이동한다.
### 예외 흐름
- 남은 포인트가 없으면 정산을 건너뛴다.
- 처리에 실패하면 기존 포인트를 유지하고 오류를 안내한다.
## 발자취 조회
### 목적
사용자가 부여 여행에서 남긴 기록과 추억을 돌아본다.
### 사전 조건
- 사용자가 로그인 상태다.
- 종료한 여행 기록이 존재한다.
### 기본 흐름
1. 사용자가 여행 포인트 정산을 마친다.
2. 사용자가 `나의 부여 발자취 돌아보기`를 누른다.
3. 앱이 방문한 장소, 포인트, 탐험 통계, 획득 배지, 촬영 사진을 표시한다.
4. 사용자가 사진을 크게 보거나 이전·다음 사진을 확인한다.
5. 사용자가 발자취 조회를 마치고 지도로 돌아간다.
### 예외 흐름
- 여행 기록이 없으면 조회할 발자취가 없음을 안내한다.
- 조회에 실패하면 네트워크 오류를 안내한다.
