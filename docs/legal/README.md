## 작성 기준

이 문서는 2026-08-18 현재 백엔드 스키마, 도메인 규칙, API 명세와 운영 문서를 기준으로 작성했다. 문서에 없는 개인정보 처리를 임의로 추가하지 않았다.

현재 확인된 처리 범위는 다음과 같다.

| 구분 | 실제 처리 내용 | 저장 여부 및 기간 |
| --- | --- | --- |
| 소셜 인증 | 카카오·Apple 제공자, 제공자별 사용자 식별자 | 회원 탈퇴 확정 시 서비스 DB 연결 삭제 |
| 인증 | 회원·세션 ID, 리프레시 토큰 해시, 만료·폐기 시각 | 세션 유효기간 30일, 로그아웃·탈퇴 시 폐기 |
| 프로필·군민증 | 표시 이름, 캐릭터·테마, 시연용 바코드 | 회원 탈퇴 후 30일 이내 파기 |
| 서비스 이용 | 약관 동의, 설정, 저장 장소, 여행, 미션·답안, 방문 장소·시각, 포인트, 배지, 알림 | 회원 탈퇴 후 30일 이내 파기 |
| 현재 위치 | 위도·경도, 정확도, 측정 시각 | 요청 처리에 사용하고 원시 좌표는 DB에 저장하지 않음 |
| 위치 파생 기록 | 미션 완료로 확정된 방문 장소·시각 | 회원 탈퇴 후 30일 이내 파기 |
| 사진 | 촬영 원본, MIME 유형, 크기, 비공개 객체 키, 촬영 미션 연결 정보 | 제출 사진은 탈퇴 후 30일 이내, 미제출 객체는 24시간 후 파기 예정 |
| 푸시 | FCM 등록 토큰, 알림 설정, 발송 대상·내용·읽음 시각 | 로그아웃 시 현재 세션 토큰 삭제, 탈퇴 후 30일 이내 관련 기록 파기 |
| 접속 기록 | IP 주소, User-Agent, 요청 경로·시각, 상태 코드, 요청 ID | CloudWatch 30일 보관 예정 |
| 백업 | RDS 자동 백업 | 7일 보관 예정 |

## 출시 전 차단 항목

다음 항목은 약관 문구가 아니라 구현 또는 운영 결정을 먼저 고쳐야 한다.

1. `term_type`과 `TermType`의 `LOCATION` 추가는 구현했다. 배포 전 해당 마이그레이션과 버전별 동의 저장을 운영 환경에서 검증한다.
2. 현재 `PRIVACY`는 `개인정보 처리방침 동의`가 아니라 `개인정보 수집·이용 동의`로 사용한다. 개인정보 처리방침은 체크박스 없이 언제든 열람할 수 있게 제공한다.
3. 위치정보법상 위치정보 이용 사실 확인자료를 자동 기록하는 전용 테이블과 6개월 보존·파기 작업을 구현한다. 원시 좌표는 기록하지 않고 회원, 기능, 이용 시각, 처리 결과 등 최소 확인자료만 남긴다.
4. 탈퇴 즉시 서비스 DB의 소셜 계정 연결을 삭제하고 30일 이내 회원 행까지 파기하는 정책을 운영 배포와 재가입 통합 테스트에서 검증한다.
5. 사진 업로드 전에 EXIF 위치정보 등 메타데이터를 제거한다. 제거 전 출시한다면 원본 메타데이터 처리 사실을 처리방침에 그대로 공개해야 한다.
6. Cloudflare와 Google Firebase Cloud Messaging의 계약 주체, 이전 국가, 이전 시기·방법, 보유기간, 연락처를 확정해 처리위탁·국외이전 표를 완성한다.
7. 개발용 싱가포르 Supabase에 실제 이용자 데이터를 저장하지 않는다. 이미 생성한 실제 카카오 테스트 계정은 테스트 종료 후 삭제하고, 운영은 확정된 국내 리전 인프라를 사용한다.
8. 운영자명, 대표자, 사업자 주소, 고객센터, 개인정보 보호책임자와 위치정보관리책임자를 확정한다.
9. 위치기반서비스사업 신고 대상과 신고 시점을 관할 기관 또는 전문가에게 확인한다. 소상공인·1인 창조기업도 계속 사업하면 개시 후 1개월 이내 신고가 필요할 수 있다.
10. 만 14세 미만 이용을 허용할지 결정한다. MVP 권장안은 만 14세 이상으로 제한하는 것이며, 허용하려면 법정대리인 동의 확인 절차를 별도로 구현한다.

위 차단 항목을 구현하기 전에는 초안의 `30일 이내 파기`, `미제출 사진 24시간 파기`, `위치 이용 사실 6개월 보관`, `만 14세 이상 제한` 문구를 실제 운영 정책으로 게시해서는 안 된다. 코드와 운영 절차가 문구를 충족하는지 먼저 검증한다.

## 현재 외부 연동 판단

- 카카오·Apple: 소셜 인증에 사용하며 백엔드는 이메일, 전화번호, 실명, 생년월일을 요청하거나 저장하지 않는다.
- AWS 서울 리전: 운영 DB, 비공개 사진 저장소와 로그 저장소로 예정되어 있다.
- Google FCM: 푸시 알림 구현 시 등록 토큰과 알림 데이터가 처리된다.
- Cloudflare: 운영 도메인의 보안·프록시로 사용하면 IP 주소와 요청 메타데이터를 처리한다.
- 관광데이터 API·VWorld: 현재 사용자 요청 시 좌표나 회원정보를 전송하는 런타임 연동은 확인되지 않았다. 공개 관광지·경계 원본을 서버 데이터로 적재하는 것은 이용자 개인정보 제3자 제공에 해당하지 않는다.
