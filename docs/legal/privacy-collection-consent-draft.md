# 개인정보 수집·이용 동의 초안

> [필수] 개인정보 수집·이용 동의

> 이 초안의 보유기간은 `README.md`의 출시 전 차단 항목을 구현한다는 전제다. 현재 코드 상태 그대로 게시하지 않는다.

[운영자명](이하 “운영자”)은 부여ON 회원 가입과 서비스 제공을 위해 다음과 같이 개인정보를 수집·이용합니다.

| 수집·이용 목적 | 수집 항목 | 보유·이용 기간 |
| --- | --- | --- |
| 회원 식별 및 소셜 로그인 | 카카오 또는 Apple 구분, 해당 제공자가 발급한 사용자 식별자, 회원 ID | 회원 탈퇴 후 30일 이내 파기. 단, 출시 전 확정된 법적 보존 사유가 있으면 그 기간 |
| 로그인 유지와 보안 | 인증 세션 ID, 리프레시 토큰 해시, 세션 생성·만료·폐기 시각 | 세션 종료 또는 만료 시까지. 세션 최대 30일 |
| 필수 약관 동의 관리 | 약관 유형·버전, 동의 여부와 동의 시각 | 회원 탈퇴 후 30일 이내 파기. 분쟁 대응을 위한 별도 보존 여부는 출시 전 확정 |
| 서비스 제공 및 이용 기록 관리 | 표시 이름, 선택한 캐릭터·카드 테마, 군민증 식별자·시연용 바코드, 회원 설정, 저장 장소, 여행 시작·종료 시각, 미션 참여·답안·완료 기록, 방문 장소·시각, 포인트·배지, 알림 기록 | 회원 탈퇴 후 30일 이내 파기 |
| 서비스 보안과 장애 대응 | IP 주소, User-Agent, 요청 경로·시각, 응답 상태, 요청 ID | 수집일로부터 30일 |

운영자는 카카오·Apple로부터 이메일, 전화번호, 실명, 생년월일 또는 성별을 제공받거나 저장하지 않습니다.

이용자는 동의를 거부할 권리가 있습니다. 다만 위 정보는 회원 식별과 핵심 서비스 제공에 필요한 최소 정보이므로 동의를 거부하면 회원 가입 및 회원 전용 서비스를 이용할 수 없습니다.

위치정보, 미션 사진과 마케팅 정보는 이 동의에 포함하지 않으며 각 기능 또는 별도 동의에서 안내합니다.
