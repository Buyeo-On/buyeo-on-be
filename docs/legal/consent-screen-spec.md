# 동의 화면 및 데이터 모델 명세

## 가입 단계

다음 항목은 서로 구분해 각각 제목, 전문 보기, 선택 상태를 제공한다.

| 화면 항목 | 필수 여부 | DB 유형 | 비고 |
| --- | --- | --- | --- |
| 서비스 이용약관 | 필수 | `SERVICE` | 서비스 계약 조건 |
| 개인정보 수집·이용 동의 | 필수 | `PRIVACY` | 처리방침 동의가 아님 |
| 위치기반서비스 이용약관 | 필수 | `LOCATION` | 여행 시작·미션 위치 판정 |
| 마케팅 정보 수신 동의(앱 푸시) | 선택 | `MARKETING` | 거부해도 서비스 이용 가능 |

`전체 동의`는 편의 기능일 뿐이며 선택 항목까지 강제하면 안 된다. 전체 동의를 해제해도 각 항목을 다시 개별 선택할 수 있어야 한다.

개인정보 처리방침은 체크박스 항목으로 만들지 않고 가입 화면과 설정 화면에서 항상 열람할 수 있는 링크로 제공한다.

## 기능 사용 시 별도 권한·안내

| 시점 | 필요한 처리 |
| --- | --- |
| 여행 시작 또는 위치 기능 최초 사용 | 위치기반서비스 약관 동의 확인 후 iOS·Android 위치 권한 요청 |
| 사진 미션 최초 사용 | 수집 목적·항목·보유기간을 짧게 고지한 뒤 카메라 권한 요청 |
| 근처 퀴즈 알림 활성화 | 위치·알림 권한 확인. 이는 서비스 알림 설정이며 마케팅 동의와 분리 |
| 할인·행사·부여 소식 알림 활성화 | 마케팅 수신 동의와 OS 알림 권한을 모두 확인 |

OS 권한 허용은 법적 약관 동의를 대신하지 않고, 약관 동의도 OS 권한을 대신하지 않는다.

## 백엔드 변경 요구사항

1. PostgreSQL `term_type` enum과 Java `TermType`의 `LOCATION`을 유지하고 API 계약과 함께 검증한다.
2. 기존 `PRIVACY` 약관 제목을 `개인정보 수집·이용 동의`로 고정한다.
3. 서비스가 실제로 사용하는 현재 버전 전체를 반환하고, 새 필수 버전 시행 시 재동의를 요구한다.
4. 동의 기록에는 회원, 약관 ID·유형·버전, 동의 여부, 동의 시각을 보존한다.
5. 선택 마케팅 동의 철회 API를 제공하고 철회 즉시 광고성 푸시 대상에서 제외한다.
6. 위치 약관 동의 철회 시 위치 기반 기능을 중단하되 비위치 기능과 탈퇴 경로는 계속 제공한다.
7. 위치정보 이용 사실 확인자료를 별도 기록하고 6개월 후 자동 파기한다.

## 가입 완료 조건

- `SERVICE`, `PRIVACY`, `LOCATION`의 현재 버전이 모두 `agreed=true`여야 한다.
- `MARKETING`은 `true` 또는 `false`를 명시적으로 저장하되 가입 성공 여부에 영향을 주지 않는다.
- 사진 수집은 가입 필수 조건으로 묶지 않는다.
